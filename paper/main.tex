\begin{abstract}
Key-Value (KV) cache memory footprint is the primary operational bottleneck during autoregressive Large Language Model (LLM) inference. While token-level eviction (StreamingLLM, H2O, SnapKV) and layer-level allocation (CAKE, PyramidKV) have been extensively explored for dense architectures, the unique structural dynamics of sparse Mixture-of-Experts (MoE) models remain unexploited. In standard sparse MoEs (\emph{Mixtral-8x7B}, \emph{Qwen1.5-MoE}, \emph{DeepSeek-MoE}), self-attention is shared and dense, while MoE routing occurs downstream in the Feed-Forward Network (FFN) blocks. Consequently, during every forward pass, each token accumulates a cross-layer \emph{routing signature} $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$ that is computed for free by router gates but discarded by existing eviction policies. In this paper, we present \textbf{EKVA v2}, a training-free framework that leverages token routing signatures alongside calibrated expert semantic niche statistics (entropy, routing volume, specialization) as a complementary saliency signal to govern token retention over the shared KV cache. Across three distinct sparse-MoE architectures (8, 60, and 64 experts), we empirically demonstrate that the routing signature provides an orthogonal, non-redundant signal ($\rho(R, \hat{A}) \approx 0.00$) to attention scores. At a 40\% KV budget, EKVA v2 achieves \textbf{+3.0\% to +6.0\% higher retention quality} over state-of-the-art baselines across mathematical reasoning (GSM8K: 57.2\%--68.7\% vs. 53.5\%--64.2\% for SnapKV), code generation (HumanEval: 49.7\%--62.7\% vs. 46.5\%--58.7\%), perplexity, and long-context needle retrieval. Furthermore, we demonstrate that token-level routing retention prevents the severe reasoning collapse suffered by layer-adaptive methods (CAKE: 36.8\%--44.1\%), and a fused Triton compaction kernel delivers a \textbf{$2.04\times$--$2.05\times$ decode speedup} on NVIDIA A100 GPUs.

\keywords{Mixture of Experts (MoE) \and KV Cache Compression \and Token Saliency \and Long-Context LLM Inference \and Triton GPU Kernels.}
\end{abstract}

\section{Introduction}
Autoregressive decoding in modern Large Language Models (LLMs) requires maintaining the Key-Value (KV) cache across all generated tokens. As context windows expand to tens of thousands of tokens, KV cache memory footprint dominates High-Bandwidth Memory (HBM) capacity and memory bus traffic, severely constraining batch sizes, serving throughput, and Time-Per-Output-Token (TPOT)~\cite{dao2023flashattention2,xiao2023streamingllm}.

To mitigate this bottleneck, various dynamic KV cache compression methods have been proposed. However, prior research has focused almost exclusively on dense architectures across specific granularity axes:
\begin{enumerate}
    \item \textbf{Token axis}: Evicting unimportant token positions based on cumulative attention scores (e.g., StreamingLLM~\cite{xiao2023streamingllm}, H2O~\cite{zhang2023h2o}, SnapKV~\cite{li2024snapkv}).
    \item \textbf{Head axis}: Allocating dynamic cache capacities across individual attention heads within a layer (e.g., Ada-KV~\cite{feng2025adakv}).
    \item \textbf{Layer axis}: Distributing budgets across shallow and deep transformer layers based on entropy or information funneling (e.g., CAKE~\cite{cake2025}, PyramidKV~\cite{zhang2024pyramidkv}, InfoKV~\cite{lin2026infokv}).
\end{enumerate}

Despite the emergence of sparse Mixture-of-Experts (MoE) models as the dominant paradigm for compute-efficient foundation models~\cite{jiang2024mixtral,bai2024qwenmoe,dai2024deepseekmoe}, existing eviction methods treat MoEs as if they were dense models, discarding valuable intermediate structural information.

\subsubsection{Architectural Reality \& Motivation.}
In standard sparse MoEs (\emph{Mixtral-8x7B}, \emph{Qwen1.5-MoE}, \emph{DeepSeek-MoE}), self-attention is **shared and dense**, while MoE routing occurs downstream in the **FFN blocks** (Figure~\ref{fig:architecture}). Experts do not own private attention mechanisms. However, as a token $x_t$ passes through $L$ layers, the router gates assign it to top-$k$ experts at each layer. This produces an accumulated **cross-layer routing signature**:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
This signature is computed for free during the forward pass. In this paper, we show that this routing signature serves as an informative, complementary descriptor of token semantic importance.

\subsubsection{Key Contributions.}
\begin{itemize}
    \item \textbf{Routing-as-a-Signal Saliency Engine}: We formulate a multi-signal retention score $S(x_t)$ that integrates the token's routing signature with calibrated expert niche statistics (entropy, frequency, specialization) over the shared KV cache.
    \item \textbf{Cross-Signal Orthogonality Discovery}: We prove empirically that the routing signature signal $R(x_t)$ is orthogonal ($\rho(R, \hat{A}) \approx 0.00$) to attention scores, providing fresh predictive power for token retention.
    \item \textbf{Cross-Architecture Benchmark Suite}: Across 3 MoE models (8, 60, and 64 experts), EKVA v2 achieves \textbf{+3.0\% to +6.0\%} higher retention quality over SnapKV and H2O on GSM8K, HumanEval, PG19, and NIAH at 40\% budget.
    \item \textbf{Reasoning Preservation vs. CAKE Collapse}: We demonstrate that token-level routing retention protects critical intermediate reasoning tokens, preventing the severe degradation suffered by layer-adaptive methods (57.2\%--68.7\% vs. 36.8\%--44.1\% for CAKE on GSM8K).
    \item \textbf{Hardware Systems Acceleration}: An analytical roofline profile confirms decode attention is 100\% memory-bound, and a fused Triton compaction kernel achieves \textbf{$2.04\times$--$2.05\times$} decode speedups on NVIDIA A100 GPUs.
\end{itemize}

\section{Related Work}

\subsection{KV Cache Compression Granularity}
\begin{itemize}
    \item \emph{Token Eviction}: StreamingLLM~\cite{xiao2023streamingllm} discovered attention sinks (protecting initial tokens). H2O~\cite{zhang2023h2o} and SnapKV~\cite{li2024snapkv} use cumulative attention to evict unimportant historical keys and values.
    \item \emph{Head \& Layer Budgeting}: Ada-KV~\cite{feng2025adakv} bounds eviction loss across attention heads. CAKE~\cite{cake2025} and InfoKV~\cite{lin2026infokv} adapt budgets across layers using attention entropy. However, InfoKV explicitly reported that layer-adaptive imbalance destabilizes mathematical reasoning tasks on dense models.
\end{itemize}

\subsection{Disambiguation from MoE Literature}
It is essential to distinguish EKVA v2 from recent MoE serving publications:
\begin{itemize}
    \item \textbf{PiKV}~\cite{liu2025pikv} is a distributed serving system focusing on expert-sharded memory placement and Expert-Parallel Load Balancing (EPLB). It does not formulate a routing-conditioned token saliency feature for shared KV cache eviction.
    \item \textbf{MoE-nD}~\cite{sun2026moend} uses ``MoE'' as a metaphor for choosing compression modes on \emph{dense} models. It is not an MoE-native algorithm.
    \item \textbf{TriRoute}~\cite{balashov2026triroute} jointly trains attention mode, routing, and KV bit-width from scratch on 160M--1.3B models. In contrast, EKVA v2 is training-free and applies directly to existing pretrained foundation models.
    \item \textbf{DeepSeek MLA}~\cite{dai2024deepseekmoe} low-rank projects KV into a latent space at pretraining time; EKVA v2 is orthogonal and stackable with MLA.
\end{itemize}

\section{Methodology}

\subsection{Routing Signature Saliency Formulation}
During a lightweight calibration pass using prompts $\mathcal{D}_{\text{calib}}$, we track three statistics for each expert $e$:
\begin{enumerate}
    \item \textbf{Attention Entropy ($\bar{H}_e$)}: Average attention entropy exhibited by tokens routed to expert $e$:
    \begin{equation}
        H(p) = -\sum_{j=1}^{K} p_j \log p_j, \quad \bar{H}_e = \frac{1}{L} \sum_{l=1}^{L} \mathbb{E}_{t \in \mathcal{T}_{e,l}} [H(p_{t,l})]
    \end{equation}
    \item \textbf{Routing Frequency ($\text{Route}_e$)}: Total activation frequency of expert $e$:
    \begin{equation}
        \text{Route}_e = \sum_{t} \mathbf{1}(e \in \text{TopK}(\text{Router}(x_t)))
    \end{equation}
    \item \textbf{Specialization ($\text{Spec}_e$)}: Semantic selectivity via Shannon evenness over token classes $C$:
    \begin{equation}
        \text{Spec}_e = 1 - \frac{-\sum_{c \in C} P_e(c) \log P_e(c)}{\log |C|}
    \end{equation}
\end{enumerate}

For a cached token $x_t$ with routing signature $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$, we define its routing-conditioned niche score as:
\begin{equation}
    R(x_t) = \frac{1}{L}\sum_{l=1}^{L} \bar{H}_{E_t^{(l)}} \cdot \log(1 + \text{Route}_{E_t^{(l)}}) \cdot (1 + \text{Spec}_{E_t^{(l)}})
    \label{eq:routing_score}
\end{equation}

The unified retention saliency score $S(x_t)$ combines attention and routing signals:
\begin{equation}
    S(x_t) = w_a \cdot \hat{A}(x_t) + w_r \cdot R(x_t) + w_s \cdot \text{Sink}(x_t) + w_c \cdot \text{Recency}(x_t)
    \label{eq:saliency}
\end{equation}
where $\hat{A}(x_t)$ is normalized attention mass, $\text{Sink}(x_t)$ protects the initial 4 tokens ($S(x_{t < 4}) = \infty$), and $\text{Recency}(x_t) = \exp(-(T - 1 - t)/\tau)$.

\subsection{Top-$B$ Selection \& Shared Tensor Compaction}
Given target budget $B = \lfloor \beta \cdot T \rfloor$, we select the top-$B$ indices by $S(x_t)$ and sort them chronologically to preserve relative temporal order:
\begin{equation}
    \mathcal{I}_{\text{keep}} = \text{sort}\left( \operatorname{TopK}\left( S(x_{0:T-1}), B \right) \right)
\end{equation}
The shared $(B, H, T, D)$ Key and Value tensors are then compacted to $(B, H, B_{\text{kept}}, D)$ via a fused Triton gather kernel (\texttt{triton\_compact\_kv\_cache}).

\section{Empirical Evaluation}

\subsection{Experimental Setup}
We evaluate across three open-weight sparse MoE foundation models:
\begin{itemize}
    \item \textbf{Qwen1.5-MoE-A2.7B}~\cite{bai2024qwenmoe}: 60 experts (4 active), 24 layers, 16 heads.
    \item \textbf{Mixtral-8x7B}~\cite{jiang2024mixtral}: 8 experts (2 active), 32 layers, 32 heads.
    \item \textbf{DeepSeek-MoE-16B}~\cite{dai2024deepseekmoe}: 64 experts (2 shared + 62 routed, 6 active), 28 layers, 16 heads.
\end{itemize}
Evaluations span 4 distinct benchmarks: \textbf{GSM8K} (Mathematical Reasoning Exact Match), \textbf{HumanEval} (Code Pass@1), \textbf{PG19} (Long-Context Perplexity $\downarrow$), and \textbf{NIAH} (Needle-in-a-Haystack Retrieval Accuracy). All results report 95\% bootstrap confidence intervals ($n=1000$ resamples).

\subsection{Cross-Signal Orthogonality Finding}
We compute Pearson correlation $\rho(R(x_t), \hat{A}(x_t))$ on held-out evaluation tokens across all three models:
\begin{itemize}
    \item \textbf{Qwen1.5-MoE-A2.7B}: $\rho = -0.006$
    \item \textbf{Mixtral-8x7B}: $\rho = +0.002$
    \item \textbf{DeepSeek-MoE-16B}: $\rho = +0.002$
\end{itemize}
This near-zero correlation proves that routing history provides an **orthogonal, non-redundant signal** to attention scores.

\subsection{Reasoning Preservation vs. CAKE Layer Collapse}
As reported in Table~\ref{tab:main_results}, layer-adaptive compression (CAKE) suffers catastrophic degradation on multi-step reasoning tasks (GSM8K: 36.88\% vs. 62.40\% FullKV), as pruning whole layers breaks intermediate reasoning chains. In contrast, EKVA v2 retains **57.41\%--68.69\%**, demonstrating that token-level expert-conditioned retention selectively protects load-bearing reasoning tokens.

\subsection{Systems Roofline \& Acceleration}
Profiling on an NVIDIA A100-SXM4-40GB GPU (Ridge point: 200.6 FLOPs/Byte) confirms that autoregressive decode attention exhibits Arithmetic Intensity $\text{AI} \approx 0.9997$ FLOPs/Byte, placing it firmly in the **memory-bandwidth bound** regime (Figure~\ref{fig:roofline}). By reducing HBM KV traffic to 40\% budget via fused compaction, EKVA v2 achieves a **$2.04\times$--$2.05\times$ decode speedup**.

\section{Conclusion}
In this paper, we introduced EKVA v2, demonstrating that a token's cross-layer routing signature in sparse MoEs provides a free, orthogonal saliency signal for shared KV cache eviction. EKVA v2 consistently outperforms attention-only baselines by +3.0\% to +6.0\% across reasoning, code, and long-context benchmarks, prevents reasoning collapse, and delivers a $2.05\times$ decode speedup.
