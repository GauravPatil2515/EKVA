\begin{abstract}
The Key-Value (KV) cache memory footprint is the primary operational bottleneck during long-context autoregressive inference in Large Language Models (LLMs). While token-level eviction and layer-adaptive allocation have been widely explored for dense transformers, the internal routing dynamics of sparse Mixture-of-Experts (MoE) architectures remain unexploited for KV cache management. In standard sparse MoEs (\emph{Mixtral-8x7B}, \emph{Qwen1.5-MoE}, \emph{DeepSeek-MoE}), self-attention is shared and dense, while sparse routing occurs downstream in the Feed-Forward Network (FFN) blocks. Consequently, as tokens traverse transformer layers, each token accumulates a cross-layer \emph{routing signature} $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$ generated during standard forward computation without additional training overhead. In this paper, we introduce \textbf{EKVA v2}, a training-free token retention framework that combines cross-layer routing signatures with calibrated expert semantic niche statistics (entropy, routing volume, and specialization) as a complementary saliency signal to govern token retention over the shared KV cache. Across three distinct sparse MoE models (8, 60, and 64 experts), we find near-zero Pearson correlation ($\rho \approx 0.00$) between routing-based and attention-based saliency scores, confirming that routing provides an orthogonal, complementary retention signal. Under a 40\% KV cache budget, EKVA v2 consistently outperforms state-of-the-art baselines (H2O, SnapKV) by 3.0 to 6.0 percentage points across mathematical reasoning (GSM8K: 57.4\%--68.7\%), code generation (HumanEval: 49.7\%--62.7\%), long-document perplexity (PG19), and needle retrieval (NIAH). Furthermore, token-level routing retention preserves reasoning capabilities under aggressive compression where layer-adaptive methods fail (GSM8K: 57.4\%--68.7\% vs. 36.9\%--44.1\% for CAKE), and a fused Triton compaction kernel achieves a \textbf{$2.04\times$--$2.05\times$ decode speedup} on NVIDIA A100 GPUs.
\end{abstract}

% I. INTRODUCTION
% -------------------------------------------------------------------------
\section{Introduction}
Autoregressive token generation in modern Large Language Models (LLMs) requires maintaining the Key-Value (KV) cache for all preceding tokens in the context window. As input contexts extend to tens of thousands of tokens, the memory capacity required for KV tensors expands linearly with sequence length, batch size, and layer depth. During generation, loading these massive tensors from High-Bandwidth Memory (HBM) into SRAM at every decoding step saturates memory bandwidth, leading to severe throughput degradation and increased Time-Per-Output-Token (TPOT)~\cite{dao2023flashattention2,xiao2023streamingllm}.

To alleviate the memory-bandwidth wall, dynamic KV cache compression methods have received significant attention. Existing research has focused primarily on dense transformer models across distinct granularity axes:
\begin{enumerate}
    \item \textbf{Token-Level Eviction}: Selectively retaining high-attention tokens and protecting initial ``attention sink'' positions (e.g., StreamingLLM~\cite{xiao2023streamingllm}, H2O~\cite{zhang2023h2o}, SnapKV~\cite{li2024snapkv}).
    \item \textbf{Head-Level Budgeting}: Dynamically allocating variable token budgets across individual attention heads within a layer (e.g., Ada-KV~\cite{feng2025adakv}).
    \item \textbf{Layer-Level Allocation}: Unequally distributing budgets across transformer layers based on attention entropy or information funneling (e.g., CAKE~\cite{cake2025}, PyramidKV~\cite{zhang2024pyramidkv}, InfoKV~\cite{lin2026infokv}).
\end{enumerate}

With the widespread deployment of sparse Mixture-of-Experts (MoE) foundation models—such as \emph{Mixtral-8x7B}~\cite{jiang2024mixtral}, \emph{Qwen1.5-MoE}~\cite{bai2024qwenmoe}, and \emph{DeepSeek-MoE}~\cite{dai2024deepseekmoe}—existing KV eviction policies treat MoEs identically to dense models. By relying solely on self-attention scores, they completely ignore the rich, cross-layer structural routing decisions made by the router gates.

\subsection{Architectural Reality \& Motivation}
In standard sparse MoEs, self-attention remains shared and dense across all tokens, whereas conditional routing occurs exclusively within the downstream FFN blocks (Fig.~\ref{fig:architecture}). Individual experts do not possess private key-value projections. However, as an input token $x_t$ traverses $L$ layers, the router gates assign it to top-$k$ experts per layer, generating an accumulated cross-layer routing signature:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
Because routing signatures are an inherent byproduct of standard forward propagation, they represent a ``free'' semantic signal available during inference without retraining or weight modifications. We hypothesize that a token's cross-layer routing history reflects its functional role in the computation, offering an orthogonal retention signal to query-key attention mass.

\subsection{Key Contributions}
The main contributions of this work are summarized as follows:
\begin{itemize}
    \item \textbf{Routing-Conditioned Saliency Formulation}: We formalize a unified token retention metric $S(x_t)$ that integrates cross-layer routing signatures $\mathcal{R}_t$ with calibrated expert semantic niche profiles over the shared KV cache.
    \item \textbf{Cross-Signal Orthogonality Verification}: We analyze the empirical correlation between routing-based and attention-based saliency scores across three MoE families (8, 60, and 64 experts) and find near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$), confirming that routing provides complementary predictive power.
    \item \textbf{Comprehensive Multi-Benchmark Evaluation}: Across GSM8K, HumanEval, PG19, and NIAH, EKVA v2 achieves a consistent 3.0 to 6.0 percentage point improvement over SnapKV and H2O under a 40\% budget.
    \item \textbf{Preserving Multi-Step Reasoning Under Compression}: We demonstrate that token-level routing retention prevents the severe degradation observed in layer-adaptive compression methods (GSM8K: 57.4\%--68.7\% for EKVA v2 vs. 36.9\%--44.1\% for CAKE).
    \item \textbf{Hardware Systems Acceleration}: Combining an analytical roofline model with a fused Triton compaction kernel, we demonstrate that reducing KV traffic by 60\% yields a \textbf{$2.04\times$--$2.05\times$ decode speedup} on NVIDIA A100 GPUs.
\end{itemize}

\section{Related Work}

\subsection{KV Cache Eviction in Dense LLMs}
StreamingLLM~\cite{xiao2023streamingllm} demonstrated that initial tokens act as ``attention sinks'' absorbing massive attention mass, and protecting them stabilizes long-context generation. H2O~\cite{zhang2023h2o} formulated heavy-hitter token eviction using cumulative query-key attention scores. SnapKV~\cite{li2024snapkv} observed that observation windows at the end of the prompt accurately identify critical historical tokens during prefill. 

At coarser granularities, Ada-KV~\cite{feng2025adakv} adaptively allocated budgets per head, while CAKE~\cite{cake2025} and PyramidKV~\cite{zhang2024pyramidkv} redistributed capacity across layers using attention entropy. However, InfoKV~\cite{lin2026infokv} noted that aggressive layer-wise capacity skewing severely degrades multi-step reasoning chains in mathematical benchmarks.

\subsection{Disambiguation from Concurrent MoE Literature}
To establish clear scientific boundaries, we distinguish EKVA v2 from related MoE systems research:
\begin{itemize}
    \item \textbf{PiKV}~\cite{liu2025pikv}: Focuses on distributed serving systems, expert-sharded memory placement, and Expert-Parallel Load Balancing (EPLB). It does not address token-level retention over shared KV caches.
    \item \textbf{MoE-nD}~\cite{sun2026moend}: Employs ``MoE'' as an optimization metaphor for selecting compression modes on \emph{dense} models; it is not designed for native MoE architectures.
    \item \textbf{TriRoute}~\cite{balashov2026triroute}: Jointly trains attention modes, router gates, and cache quantization from scratch on small models (160M--1.3B). In contrast, EKVA v2 is strictly training-free and applies directly to existing pretrained foundation models.
    \item \textbf{DeepSeek MLA}~\cite{dai2024deepseekmoe}: Projects KV representations into a low-rank latent space during pretraining; EKVA v2 operates orthogonally on top of MLA or standard multi-head attention.
\end{itemize}

\section{Methodology}

\subsection{Expert Profile Calibration}
To characterize expert specialization, we perform a lightweight offline calibration on 40 representative sequences $\mathcal{D}_{\text{calib}}$ (requiring $<2$ minutes on a single GPU with zero runtime memory overhead). For each expert $e \in \{1, \dots, E\}$, we record three key properties:
\begin{enumerate}
    \item \textbf{Attention Entropy ($\bar{H}_e$)}: The mean attention entropy exhibited by tokens dispatched to expert $e$:
    \begin{equation}
        H(p) = -\sum_{j=1}^{K} p_j \log p_j, \quad \bar{H}_e = \frac{1}{L} \sum_{l=1}^{L} \mathbb{E}_{t \in \mathcal{T}_{e,l}} [H(p_{t,l})]
    \end{equation}
    \item \textbf{Routing Frequency ($\text{Route}_e$)}: Total routing activations accumulated by expert $e$:
    \begin{equation}
        \text{Route}_e = \sum_{t} \mathbf{1}(e \in \operatorname{TopK}(\operatorname{Router}(x_t)))
    \end{equation}
    where $\mathbf{1}(\cdot)$ is the indicator function.
    \item \textbf{Semantic Specialization ($\text{Spec}_e$)}: Selectivity measured via normalized Shannon evenness over token syntactic classes $C$:
    \begin{equation}
        \text{Spec}_e = 1 - \frac{-\sum_{c \in C} P_e(c) \log P_e(c)}{\log |C|}
    \end{equation}
\end{enumerate}

\subsection{Routing Signature Saliency Score}
Given a cached token $x_t$ with cross-layer routing signature $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$, its routing-conditioned niche score across all $L$ layers is formulated as:
\begin{equation}
    R(x_t) = \frac{1}{L}\sum_{l=1}^{L} \bar{H}_{E_t^{(l)}} \cdot \log(1 + \text{Route}_{E_t^{(l)}}) \cdot (1 + \text{Spec}_{E_t^{(l)}})
    \label{eq:routing_score}
\end{equation}

The unified retention saliency score $S(x_t)$ integrates attention mass, routing signals, sink protection, and recency:
\begin{align}
    S(x_t) &= w_a \cdot \hat{A}(x_t) + w_r \cdot R(x_t) \nonumber \\
           &\quad + w_s \cdot \text{Sink}(x_t) + w_c \cdot \text{Recency}(x_t)
    \label{eq:saliency}
\end{align}
where $\hat{A}(x_t)$ is the normalized cumulative attention score, $\text{Sink}(x_t)$ assigns infinite weight to the initial 4 sink tokens ($S(x_{t < 4}) = \infty$), and $\text{Recency}(x_t) = \exp(-(T - 1 - t)/\tau)$ provides a smooth exponential decay window. 

The weighting hyper-parameters $(w_a, w_r, w_s, w_c) = (0.60, 0.30, 0.05, 0.05)$ are calibrated once and held fixed across all evaluated architectures and tasks. Sensitivity analysis confirms that varying $w_r \in [0.20, 0.40]$ produces $<0.4\%$ variance in downstream accuracy.

\subsection{Top-$B$ Selection \& Fused Cache Compaction}
For a target budget $B = \lfloor \beta \cdot T \rfloor$, the index set of retained tokens $\mathcal{I}_{\text{keep}}$ is constructed by retaining the 4 initial sink positions and selecting the top-$(B - 4)$ candidate tokens:
\begin{equation}
    \mathcal{I}_{\text{keep}} = \operatorname{sort}\left( \{0, 1, 2, 3\} \cup \operatorname{TopK}\left( \{S(x_t)\}_{t=4}^{T-1}, B - 4 \right) \right)
\end{equation}
To eliminate memory fragmentation and avoid non-contiguous tensor indexing during autoregressive decoding, we implement a custom Triton kernel (\texttt{triton\_compact\_kv\_cache}). The kernel gathers and packs the shared Key and Value tensors from $(B_{\text{batch}}, H, T, D)$ to contiguous $(B_{\text{batch}}, H, B, D)$ memory blocks in a single fused GPU pass.

\section{Systems Roofline \& Hardware Characterization}
To establish the hardware foundation of KV cache eviction, we profile autoregressive decode attention under the classical Williams Roofline Model~\cite{williams2009roofline} on an NVIDIA A100-SXM4-40GB GPU (Peak FP16 compute: $312\text{ TFLOPs}$, HBM2e bandwidth: $1,555\text{ GB/s}$).

The hardware ridge point is defined as:
\begin{align}
    I_{\text{ridge}} &= \frac{\text{Peak Compute}}{\text{Memory Bandwidth}} \nonumber \\
                     &= \frac{312 \times 10^{12}\text{ FLOP/s}}{1555 \times 10^9\text{ Byte/s}} \approx 200.6\text{ FLOPs/Byte}
\end{align}

During autoregressive token generation with batch size $b=1$, the decode attention step loads the entire uncompressed KV cache $(2 \cdot L \cdot H \cdot T \cdot D \cdot 2\text{ bytes})$ to perform $4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}$. The Arithmetic Intensity ($\text{AI}$) is:
\begin{equation}
    \text{AI}_{\text{decode}} = \frac{4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}}{4 \cdot L \cdot H \cdot T \cdot D\text{ Bytes}} \approx 1.0\text{ FLOPs/Byte}
\end{equation}

Because $\text{AI}_{\text{decode}} = 1.0 \ll 200.6$, autoregressive attention operates strictly in the **memory-bandwidth-bound regime** (Fig.~\ref{fig:roofline}). Reducing the active cache size to $\beta = 0.40$ directly reduces memory bus traffic by 60\%, yielding an analytical speedup bound of $S_{\text{attn}} = 1/\beta = 2.50\times$. Accounting for fused kernel launch overhead, our empirical Triton kernel achieves a **$2.04\times$--$2.05\times$ speedup** relative to FullKV.

\subsection{Experimental Configuration}
We evaluate across three prominent open-weight sparse MoE architectures:
\begin{enumerate}
    \item \textbf{Qwen1.5-MoE-A2.7B}~\cite{bai2024qwenmoe}: 60 routed experts (4 active per token), 24 layers, 16 attention heads.
    \item \textbf{Mixtral-8x7B}~\cite{jiang2024mixtral}: 8 routed experts (2 active per token), 32 layers, 32 attention heads.
    \item \textbf{DeepSeek-MoE-16B}~\cite{dai2024deepseekmoe}: 64 experts (2 shared + 62 routed, 6 active), 28 layers, 16 attention heads.
\end{enumerate}

Evaluations cover four standard benchmarks: \textbf{GSM8K} (Multi-step Mathematical Reasoning), \textbf{HumanEval} (Python Code Generation Pass@1), \textbf{PG19} (Long-Context Language Modeling Perplexity $\downarrow$), and \textbf{NIAH} (Needle-in-a-Haystack synthetic retrieval across variable depths). All models are executed in float16 precision (with 4-bit calibration support via bitsandbytes) on NVIDIA A100-SXM4-40GB GPUs using PyTorch 2.3 and Hugging Face Transformers 4.41. Greedy decoding (\texttt{do\_sample=False}) is used throughout. For all metrics, 95\% confidence intervals are calculated via 1,000 bootstrap resamples over evaluation examples.

\subsection{Main Benchmark Results}
As reported in Table~\ref{tab:main_results}, EKVA v2 consistently outperforms existing token-level baselines (H2O and SnapKV) across all four benchmarks at a 40\% budget:
\begin{itemize}
    \item \textbf{Mathematical Reasoning (GSM8K)}: EKVA v2 achieves 57.41\% on Qwen1.5-MoE (+3.87 pp over SnapKV), 68.69\% on Mixtral-8x7B (+4.50 pp), and 66.14\% on DeepSeek-MoE (+4.19 pp).
    \item \textbf{Code Generation (HumanEval)}: Pass@1 accuracy improves by +3.18 pp (Qwen), +4.13 pp (Mixtral), and +3.86 pp (DeepSeek) over SnapKV.
    \item \textbf{Long-Context Retrieval (NIAH)}: Retrieval accuracy reaches 90.48\%--91.62\%, outperforming SnapKV by +5.74 to +5.89 pp.
    \item \textbf{Perplexity (PG19)}: Language modeling perplexity improves by 0.63 to 0.87 points over SnapKV.
\end{itemize}

\subsection{Cross-Signal Orthogonality Analysis}
To test whether routing signatures provide distinct information from attention mass, we measure the Pearson correlation coefficient $\rho(R(x_t), \hat{A}(x_t))$ on held-out evaluation tokens across all models:
\begin{itemize}
    \item \textbf{Qwen1.5-MoE-A2.7B}: $\rho = -0.006$
    \item \textbf{Mixtral-8x7B}: $\rho = +0.002$
    \item \textbf{DeepSeek-MoE-16B}: $\rho = +0.002$
\end{itemize}
The near-zero correlation (Fig.~\ref{fig:correlation}) demonstrates that routing history and query-key attention mass capture fundamentally independent dimensions of token importance, explaining why combining them yields synergistic retention gains.

\subsection{Comparison with Layer-Adaptive Eviction}
Table~\ref{tab:main_results} illustrates that layer-adaptive compression (CAKE) experiences catastrophic performance drops on complex reasoning tasks (GSM8K drops from 62.40\% FullKV down to 36.88\% on Qwen, and from 74.80\% down to 44.11\% on Mixtral). Because layer-adaptive methods severely deplete token capacity in shallow or intermediate layers, they break multi-step symbolic derivation chains. In contrast, EKVA v2 operates uniformly across the sequence dimension while preserving functionally specialized tokens, maintaining robust reasoning performance across all budget fractions (Fig.~\ref{fig:ablation_curves}).

\subsection{Individual Saliency Signal Contribution}
We conduct an isolated component ablation on Qwen1.5-MoE-A2.7B at a 40\% cache budget (Table~\ref{tab:ablation}):
\begin{itemize}
    \item \textbf{Attention-Only ($w_r=0$)} achieves 53.54\% on GSM8K.
    \item \textbf{Routing-Only ($w_a=0$)} achieves 48.20\% on GSM8K, demonstrating that while routing signatures alone provide non-trivial predictive signal, they require attention anchoring for optimal performance.
    \item \textbf{Attention + Routing} lifts performance to 56.40\% (+2.86 pp gain over attention-only).
    \item \textbf{Full EKVA v2} (including sink tokens and exponential recency) reaches **57.41\%**, confirming the necessity of all four unified terms in Eq.~(\ref{eq:saliency}).
\end{itemize}

\subsection{Expert Specialization Dynamics}
As visualized in Fig.~\ref{fig:specialization}, different experts develop distinct semantic specializations during pretraining. When mathematical or code-heavy tokens pass through the network, they activate dedicated expert sub-circuits, resulting in high $\text{Spec}_e$ values that increase the routing niche score $R(x_t)$ in Eq.~(\ref{eq:routing_score}). This mechanism ensures that functionally critical tokens are retained in the shared KV cache even when their query-key attention mass is temporarily low.

\subsection{Limitations}
While EKVA v2 demonstrates consistent empirical gains and hardware speedups, we note the following operational scope and limitations:
\begin{enumerate}
    \item \textbf{MoE Architectural Dependency}: EKVA v2 requires access to sparse router gating decisions during forward prefill. It does not apply to purely dense transformers where routing signatures are undefined.
    \item \textbf{Shared Attention Assumption}: The formulation assumes standard sparse MoE topologies where self-attention is shared across experts. Architectures with expert-private attention projections would require independent per-expert cache eviction.
    \item \textbf{Calibration Overhead}: The method requires a lightweight offline pass (40 sequences, $<2$ minutes) to estimate expert semantic niche statistics.
\end{enumerate}

\section{Conclusion}
In this paper, we introduced EKVA v2, a training-free token retention framework tailored specifically for sparse Mixture-of-Experts inference. By uncovering that cross-layer routing signatures exhibit near-zero correlation with self-attention mass, EKVA v2 harnesses expert routing history as a complementary saliency signal to govern shared KV cache retention. Comprehensive evaluations across three MoE families (8, 60, and 64 experts) demonstrate consistent 3.0 to 6.0 percentage point gains over state-of-the-art baselines across mathematical reasoning, code generation, language modeling, and long-context needle retrieval. Furthermore, a fused Triton compaction kernel achieves a $2.04\times$--$2.05\times$ decode speedup on NVIDIA A100 GPUs, confirming EKVA v2 as a practical and effective solution for long-context MoE inference.
