\begin{abstract}
During long-context autoregressive inference in Large Language Models (LLMs), the Key-Value (KV) cache memory footprint is the dominant performance bottleneck. While token-level eviction and layer-adaptive allocation have been widely explored for dense models, the internal routing dynamics of sparse Mixture-of-Experts (MoE) architectures remain unexploited. In standard sparse MoEs (\emph{Mixtral-8x7B}, \emph{Qwen1.5-MoE}, \emph{DeepSeek-MoE}), self-attention is shared and dense, while sparse routing occurs downstream in the Feed-Forward Network (FFN) blocks. Consequently, each token accumulates an internal cross-layer \emph{routing signature} $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$ during standard forward computation. In this paper, we propose \textbf{EKVA v2}, a training-free token retention framework that leverages cross-layer routing signatures and layer-specific expert niche profiles (entropy, activation frequency, and specialization) to govern eviction in the shared KV cache. Across three MoE families (8, 60, and 64 experts), routing scores exhibit near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$) with self-attention mass across all layers, demonstrating that routing captures an independent, complementary dimension of token importance. Under a 40\% cache budget, EKVA v2 outperforms state-of-the-art baselines (H2O, SnapKV) by 3.0 to 6.0 percentage points ($p < 0.01$, paired bootstrap test) across mathematical reasoning (GSM8K), code generation (HumanEval), long-context retrieval (NIAH), and language modeling (PG19). Furthermore, a fused Triton compaction kernel delivers a \textbf{$2.02\times$--$2.05\times$ decode speedup} on NVIDIA A100 GPUs.
\end{abstract}

% I. INTRODUCTION
% -------------------------------------------------------------------------
\section{Introduction}
Autoregressive decoding in modern Large Language Models (LLMs) requires storing Key-Value (KV) activations for all context tokens in High-Bandwidth Memory (HBM). As sequence lengths grow to tens of thousands of tokens, loading large KV tensors at every decoding step saturates GPU memory bandwidth, leading to severe throughput degradation and increased Time-Per-Output-Token (TPOT)~\cite{dao2023flashattention2,xiao2023streamingllm}.

Dynamic KV cache compression methods reduce this memory traffic across three main granularity axes:
\begin{enumerate}
    \item \textbf{Token-Level Eviction}: Token-level methods evaluate individual position saliency to dynamically prune redundant tokens from the sequence. StreamingLLM~\cite{xiao2023streamingllm} discovered that initial prompt tokens serve as persistent ``attention sinks'' essential for maintaining softmax numerical stability, requiring their unconditional retention. Building on this, policies such as H2O~\cite{zhang2023h2o} and SnapKV~\cite{li2024snapkv} accumulate query-key attention scores across prefill observation windows to identify historical ``heavy-hitter'' tokens that receive sustained cross-sequence focus. Tokens falling below an empirical attention threshold are discarded, bounding the KV cache to a fixed budget. However, because these policies rely exclusively on query-key dot products, they remain blind to tokens that receive modest direct attention yet carry indispensable structural information for downstream computations.
    \item \textbf{Head-Level Allocation}: Rather than enforcing uniform capacity across all attention heads within a layer, head-level budgeting exploits the functional diversity among multi-head projections. Attention heads naturally specialize into distinct behavioral roles, ranging from long-range retrieval heads that track distant entity dependencies to localized syntax heads that attend almost entirely to neighboring tokens. Frameworks such as Ada-KV~\cite{feng2025adakv} adaptively profile per-head attention variance and entropy to allocate non-uniform token quotas, pruning low-utility heads more aggressively. While this granularity optimizes intra-layer memory allocation, it continues to treat token contents through attention alone, overlooking inter-module interactions across subsequent feed-forward networks.
    \item \textbf{Layer-Level Allocation}: Layer-wise approaches redistribute the total memory budget across transformer depth based on macroscopic information flow. Techniques including CAKE~\cite{cake2025} and InfoKV~\cite{lin2026infokv} observe that early transformer layers engage in broad contextual gathering, whereas intermediate and deep layers exhibit pyramidal information funneling. Consequently, deeper layers are granted expanded token buffers while shallower layers are aggressively compressed. Nevertheless, disproportionately starving intermediate or early layers can break delicate multi-step symbolic derivation chains, precipitating severe accuracy collapses on complex mathematical and logical reasoning tasks.
\end{enumerate}

Despite the rapid ascension and widespread deployment of sparse Mixture-of-Experts (MoE) foundation models—such as \emph{Mixtral-8x7B}~\cite{jiang2024mixtral}, \emph{Qwen1.5-MoE}~\cite{bai2024qwenmoe}, and \emph{DeepSeek-MoE}~\cite{dai2024deepseekmoe}—contemporary KV cache eviction paradigms remain fundamentally oblivious to the architectural dichotomy inherent to MoE computation. Current compression frameworks treat MoE checkpoints identically to monolithic dense transformers, relying strictly on query-key attention heatmaps while entirely bypassing the sparse, content-dependent gating decisions executed by the router layers. In doing so, existing methods fail to capture the functional specialization encoded across the network's expert dispatch pathways. Consequently, tokens that are indispensable to specific downstream expert sub-circuits risk premature eviction simply because their query-key attention mass appears temporarily low, severely undermining the model's specialized reasoning capabilities.

\subsection{Architectural Insight \& Motivation}
In standard sparse MoEs, self-attention remains shared across all tokens, while conditional routing occurs strictly in subsequent FFN blocks (Fig.~\ref{fig:architecture}). As token $x_t$ traverses $L$ layers, router gates assign it to top-$k$ experts per layer, producing an accumulated routing signature:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
Because routing signatures are generated during standard forward propagation, they represent a free semantic signal available during inference without weight modification or retraining. We hypothesize that routing history reflects the functional specialization of tokens, providing an orthogonal retention signal to query-key attention mass.

\subsection{Key Contributions}
In summary, this work addresses the KV cache memory wall in sparse Mixture-of-Experts inference through three principal contributions:

\emph{1) Algorithmic Formulation:} We formulate EKVA v2, the first training-free token retention policy tailored specifically to sparse MoE topologies. By extracting cross-layer routing signatures $\mathcal{R}_t$ during prompt prefill and coupling them with layer-specific expert niche profiles (capturing attention entropy, routing activation frequency, and semantic category specialization), we define a unified token saliency metric $S(x_t)$ that operates directly over the shared KV buffer without modifying model weights or requiring fine-tuning.

\emph{2) Mechanistic Orthogonality and Reasoning Preservation:} Through extensive empirical profiling across three open-weight MoE families (Qwen1.5-MoE-A2.7B, Mixtral-8x7B, and DeepSeek-MoE-16B spanning 8 to 64 experts), we discover that routing signatures and query-key attention mass maintain near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$) across all network depths. This empirical independence demonstrates that routing decisions provide an orthogonal retention signal that protects critical reasoning tokens overlooked by standard attention-only policies. Across GSM8K, HumanEval, NIAH, and PG19 at a 40\% cache budget, EKVA v2 achieves a statistically significant 3.0 to 6.0 percentage point gain over SnapKV and H2O ($p < 0.01$, paired bootstrap test), while completely circumventing the severe accuracy collapses suffered by layer-adaptive compression methods such as CAKE.

\emph{3) Systems Roofline Grounding and Triton Acceleration:} Grounded in the Williams Roofline Model, we demonstrate that single-query decode attention operates strictly in the memory-bandwidth-bound regime ($\text{AI} \approx 1.0\text{ FLOPs/Byte} \ll 200.6$ on an NVIDIA A100 GPU), which establishes a theoretical memory traffic reduction bound of $S_{\text{attn}} = 1/\beta = 2.50\times$ under a 40\% budget. To translate these algorithmic savings into real-world wall-clock latency gains without memory fragmentation, we develop a custom fused Triton compaction kernel that packs non-contiguous Key-Value activations into contiguous buffers, achieving a measured $2.02\times$--$2.05\times$ end-to-end decode step speedup in production execution.

% II. RELATED WORK

\section{Related Work}
\subsection{KV Cache Eviction in Dense LLMs}
StreamingLLM~\cite{xiao2023streamingllm} demonstrated that initial tokens serve as ``attention sinks'' essential for stable generation. H2O~\cite{zhang2023h2o} formulated heavy-hitter token eviction using cumulative attention. SnapKV~\cite{li2024snapkv} utilized observation windows during prefill to identify key historical tokens. At coarser granularities, Ada-KV~\cite{feng2025adakv} dynamically budgeted attention heads, while CAKE~\cite{cake2025} and InfoKV~\cite{lin2026infokv} redistributed capacity across layers. However, InfoKV noted that aggressive layer-wise budget skewing disrupts multi-step reasoning in mathematical benchmarks.

\subsection{Disambiguation from Concurrent MoE Research}
\begin{itemize}
    \item \textbf{PiKV}~\cite{liu2025pikv}: Focuses on distributed serving, expert-sharded memory placement, and load balancing; it does not address token retention over shared KV caches.
    \item \textbf{MoE-nD}~\cite{sun2026moend}: Uses MoE as an optimization metaphor for selecting compression modes in dense models.
    \item \textbf{TriRoute}~\cite{balashov2026triroute}: Jointly trains attention modes and quantization from scratch on small models ($<1.3\text{B}$); EKVA v2 is strictly training-free for pretrained foundation models.
    \item \textbf{DeepSeek MLA}~\cite{dai2024deepseekmoe}: Compresses KV representations into low-rank latent projections during pretraining; EKVA v2 operates orthogonally during post-training deployment.
\end{itemize}

\section{Methodology}

\subsection{Expert Profile Calibration}
To characterize expert specialization, we perform a lightweight offline calibration pass on 40 representative multi-domain sequences $\mathcal{D}_{\text{calib}}$ ($<2$ minutes on a single GPU). Because each transformer layer $l \in \{1, \dots, L\}$ possesses independent expert parameters, we calibrate layer-specific profiles for each expert $e \in \{1, \dots, E_l\}$ across three properties:
\begin{enumerate}
    \item \textbf{Attention Entropy ($\bar{H}_{e,l}$)}: Mean attention entropy of tokens routed to expert $e$ at layer $l$:
    \begin{equation}
        H(p) = -\sum_{j=1}^{K} p_j \log p_j, \quad \bar{H}_{e,l} = \mathbb{E}_{t \in \mathcal{T}_{e,l}} [H(p_{t,l})]
    \end{equation}
    \item \textbf{Routing Frequency ($\text{Route}_{e,l}$)}: Total activations of expert $e$ at layer $l$:
    \begin{equation}
        \text{Route}_{e,l} = \sum_{t=0}^{T-1} \mathbf{1}(e \in \operatorname{TopK}(\operatorname{Router}_l(x_t)))
    \end{equation}
    where $\mathbf{1}(\cdot)$ is the indicator function.
    \item \textbf{Semantic Specialization ($\text{Spec}_{e,l}$)}: Selectivity over token syntactic classes $C$:
    \begin{equation}
        \text{Spec}_{e,l} = 1 - \frac{-\sum_{c \in C} P_{e,l}(c) \log P_{e,l}(c)}{\log |C|}
    \end{equation}
\end{enumerate}

\subsection{Routing Signature Saliency Score}
Given a cached token $x_t$ with cross-layer routing signature $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$, its routing niche score is computed by querying the layer-specific profiles:
\begin{equation}
    R(x_t) = \frac{1}{L}\sum_{l=1}^{L} \bar{H}_{E_t^{(l)}, l} \cdot \log(1 + \text{Route}_{E_t^{(l)}, l}) \cdot (1 + \text{Spec}_{E_t^{(l)}, l})
    \label{eq:routing_score}
\end{equation}

The unified token retention saliency score $S(x_t)$ integrates attention mass, routing signals, sink protection, and recency:
\begin{align}
    S(x_t) &= w_a \cdot \hat{A}(x_t) + w_r \cdot R(x_t) \nonumber \\
           &\quad + w_s \cdot \text{Sink}(x_t) + w_c \cdot \text{Recency}(x_t)
    \label{eq:saliency}
\end{align}
where $\hat{A}(x_t)$ is the normalized cumulative attention score, $\text{Sink}(x_t)$ acts as an explicit selection constraint assigning infinite priority to the first 4 tokens ($S(x_{t < 4}) = \infty$) to guarantee attention sink retention~\cite{xiao2023streamingllm}, and $\text{Recency}(x_t) = \exp(-(T - 1 - t)/\tau)$ provides an exponential decay window. 

The hyper-parameters $(w_a, w_r, w_s, w_c) = (0.60, 0.30, 0.05, 0.05)$ are calibrated once and held fixed across all architectures. Sensitivity analysis confirms that varying $w_r \in [0.20, 0.40]$ produces $<0.4\%$ variance in downstream accuracy.

\subsection{Top-$B$ Selection \& Fused Cache Compaction}
For target budget $B = \lfloor \beta \cdot T \rfloor$, the retained index set $\mathcal{I}_{\text{keep}}$ is formed by protecting the 4 initial sinks and selecting the top-$(B - 4)$ candidate tokens:
\begin{equation}
    \mathcal{I}_{\text{keep}} = \operatorname{sort}\left( \{0, 1, 2, 3\} \cup \operatorname{TopK}\left( \{S(x_t)\}_{t=4}^{T-1}, B - 4 \right) \right)
\end{equation}
To prevent non-contiguous memory access during autoregressive decoding, a custom Triton kernel (\texttt{triton\_compact\_kv\_cache}) gathers and packs Key-Value tensors into contiguous memory blocks in a single GPU pass (Algorithm~1).

\section{Systems Roofline \& Hardware Speedup}
We profile autoregressive decode attention under the Williams Roofline Model~\cite{williams2009roofline} on an NVIDIA A100-SXM4-40GB GPU (Peak FP16 compute: $312\text{ TFLOPs}$, HBM2e bandwidth: $1,555\text{ GB/s}$). The hardware ridge point is:
\begin{align}
    I_{\text{ridge}} &= \frac{\text{Peak Compute}}{\text{Memory Bandwidth}} \nonumber \\
                     &= \frac{312 \times 10^{12}\text{ FLOP/s}}{1555 \times 10^9\text{ Byte/s}} \approx 200.6\text{ FLOPs/Byte}
\end{align}

During autoregressive token generation with batch size $b=1$, decode attention loads the uncompressed KV cache $(2 \cdot L \cdot H \cdot T \cdot D \cdot 2\text{ bytes})$ to execute $4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}$. The Arithmetic Intensity ($\text{AI}$) is:
\begin{equation}
    \text{AI}_{\text{decode}} = \frac{4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}}{4 \cdot L \cdot H \cdot T \cdot D\text{ Bytes}} \approx 1.0\text{ FLOPs/Byte}
\end{equation}

Because $\text{AI}_{\text{decode}} = 1.0 \ll 200.6$, decode attention operates strictly in the **memory-bandwidth-bound regime** (Fig.~\ref{fig:roofline}). Compressing the cache to $\beta = 0.40$ reduces memory traffic by 60\%, giving a theoretical memory speedup bound of $S_{\text{attn}} = 1/\beta = 2.50\times$. 

In practical execution on an NVIDIA A100, our fused Triton kernel achieves a **$2.02\times$--$2.05\times$ end-to-end decode step speedup**:
\begin{itemize}
    \item \textbf{Qwen1.5-MoE-A2.7B}: Latency drops from $14.8\text{ ms}$ to $7.3\text{ ms}$ ($2.02\times$).
    \item \textbf{Mixtral-8x7B}: Latency drops from $38.4\text{ ms}$ to $18.7\text{ ms}$ ($2.05\times$).
    \item \textbf{DeepSeek-MoE-16B}: Latency drops from $24.6\text{ ms}$ to $12.1\text{ ms}$ ($2.04\times$).
\end{itemize}
The slight delta from the $2.50\times$ theoretical limit is due to memory-coalesced gather index packing and non-attention layers (e.g., RMSNorm and router gating).

\subsection{Experimental Setup}
We evaluate three open-weight MoE architectures:
\begin{enumerate}
    \item \textbf{Qwen1.5-MoE-A2.7B}~\cite{bai2024qwenmoe}: 60 routed experts (4 active per token), 24 layers.
    \item \textbf{Mixtral-8x7B}~\cite{jiang2024mixtral}: 8 routed experts (2 active per token), 32 layers.
    \item \textbf{DeepSeek-MoE-16B}~\cite{dai2024deepseekmoe}: 64 experts (2 shared + 62 routed, 6 active), 28 layers.
\end{enumerate}
Evaluations span four core benchmarks: \textbf{GSM8K} (Mathematical Reasoning), \textbf{HumanEval} (Python Pass@1), \textbf{PG19} (Language Modeling Perplexity), and \textbf{NIAH} (Synthetic Retrieval). All models run in FP16 precision on NVIDIA A100-SXM4-40GB GPUs with greedy decoding (\texttt{do\_sample=False}).

\subsection{Results \& Analysis}
As shown in Table~\ref{tab:main_results}, EKVA v2 achieves statistically significant gains ($p < 0.01$) across all tasks at a 40\% budget:
\begin{itemize}
    \item \textbf{GSM8K}: EKVA v2 achieves 57.41\% on Qwen (+3.87 pp over SnapKV), 68.69\% on Mixtral (+4.50 pp), and 66.14\% on DeepSeek (+4.19 pp).
    \item \textbf{HumanEval}: Pass@1 improves by +3.18 pp (Qwen), +4.13 pp (Mixtral), and +3.86 pp (DeepSeek) over SnapKV.
    \item \textbf{NIAH}: Retrieval accuracy reaches 90.48\%--91.62\% (+5.74 to +5.89 pp gain).
    \item \textbf{PG19}: Perplexity improves by 0.63 to 0.87 PPL points over SnapKV.
\end{itemize}

\subsection{Layer-wise Orthogonality Verification}
We measure the Pearson correlation coefficient $\rho_l(R(x_t), \hat{A}(x_t))$ at each layer across all models (Fig.~\ref{fig:layerwise_correlation}). The mean correlation is near-zero ($\rho = -0.006$ on Qwen, $\rho = +0.002$ on Mixtral and DeepSeek) and remains strictly within $[-0.02, +0.03]$ across all depths. This confirms that routing signatures and attention mass capture independent dimensions of token importance throughout the model.

\subsection{Comparison with Layer- and Head-Adaptive Baselines}
Table~\ref{tab:main_results} illustrates that layer-adaptive compression (CAKE) suffers severe performance degradation on multi-step reasoning (GSM8K drops from 62.40\% FullKV to 36.88\% on Qwen, and 74.80\% to 44.11\% on Mixtral). Similarly, head-adaptive allocation (Ada-KV~\cite{feng2025adakv}, 51.20\% on Qwen GSM8K) and information-funneling layer allocation (InfoKV~\cite{lin2026infokv}, 41.80\% on Qwen GSM8K) struggle because depleting capacity in shallow or intermediate layers breaks symbolic derivation chains. In contrast, EKVA v2 makes token-level retention decisions independent of layer-wide budget constraints, preserving critical tokens uniformly across the shared KV cache (Fig.~\ref{fig:ablation_curves}).

Ablation on Qwen1.5-MoE-A2.7B (Table~\ref{tab:ablation}) shows:

\subsection{Expert Specialization Dynamics}
During calibration on $\mathcal{D}_{\text{calib}}$, tokens are tagged into four syntactic categories $C$ (numerics, keywords, syntax, and natural language). Tracking empirical routing activations $P_{e,l}(c)$ shows that specific experts develop pronounced specializations ($\text{Spec}_{e,l} > 0.65$) for symbolic arithmetic and syntactic keywords (Fig.~\ref{fig:specialization}). When domain-critical tokens pass through the network, they activate specialized sub-circuits, elevating $R(x_t)$ and ensuring retention in the shared KV cache.

\subsection{Limitations}
\begin{enumerate}
    \item \textbf{MoE Architectural Dependency}: Requires sparse router gating decisions during forward prefill; not applicable to dense transformers.
    \item \textbf{Shared Attention Assumption}: Assumes shared self-attention across experts; expert-private attention topologies would require separate per-expert eviction.
    \item \textbf{Calibration Overhead}: Requires a 2-minute offline pass (40 sequences) to estimate layer-specific expert statistics.
\end{enumerate}

\section{Conclusion}
We presented EKVA v2, a training-free token retention framework for sparse Mixture-of-Experts inference. By exploiting the orthogonality between cross-layer routing signatures and self-attention mass, EKVA v2 retains critical tokens in the shared KV cache without model retraining. Across three MoE families (8, 60, and 64 experts), EKVA v2 achieves 3.0 to 6.0 pp improvements over state-of-the-art baselines across math reasoning, code generation, language modeling, and long-context retrieval under a 40\% budget. Combined with a custom Triton kernel delivering a $2.02\times$--$2.05\times$ decode speedup on NVIDIA A100 GPUs, EKVA v2 provides a practical solution for long-context MoE deployment.
