\begin{abstract}
During long-context autoregressive inference in Large Language Models (LLMs), loading Key-Value (KV) cache tensors at each decoding step saturates High-Bandwidth Memory (HBM), creating a severe memory-bandwidth bottleneck. While token-level eviction and layer-adaptive allocation have been investigated for dense transformers, existing compression policies treat sparse Mixture-of-Experts (MoE) architectures identically to monolithic dense models. In standard sparse MoEs (\emph{Qwen1.5-MoE}, \emph{Mixtral-8x7B}, \emph{DeepSeek-MoE}), self-attention is shared and dense across all tokens, while conditional routing occurs strictly downstream within the Feed-Forward Network (FFN) blocks. Consequently, each sequence token naturally accumulates a cross-layer \emph{routing signature} $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$ during standard prefill execution without requiring weight modification or retraining. In this paper, we propose \textbf{EKVA v2}, a training-free, routing-aware token retention framework tailored specifically for sparse MoE inference. EKVA v2 unifies cross-layer routing signatures with layer-specific expert niche profiles (capturing attention entropy, routing activation frequency, and categorical specialization) over the shared KV cache. Across three open-weight MoE families (spanning 8, 60, and 64 experts), empirical profiling reveals that routing signatures maintain near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$) with self-attention mass uniformly across all network depths, demonstrating that routing captures an independent, complementary dimension of token importance. Under a 40\% cache budget, EKVA v2 achieves statistically significant gains of 3.0 to 6.0 percentage points ($p < 0.01$, paired bootstrap test with $B=10,000$ resamples) over state-of-the-art baselines (H2O, SnapKV) across mathematical reasoning (GSM8K), code synthesis (HumanEval), long-context retrieval (NIAH), and language modeling (PG19), while preventing the severe reasoning collapse observed in layer-adaptive methods (CAKE, InfoKV). Furthermore, a custom fused Triton compaction kernel delivers a measured \textbf{$2.02\times$--$2.05\times$ end-to-end decode step speedup} on NVIDIA A100 GPUs.
\end{abstract}

% I. INTRODUCTION
% -------------------------------------------------------------------------
\section{Introduction}
Autoregressive decoding in modern Large Language Models (LLMs) requires loading accumulated Key-Value (KV) activation tensors from High-Bandwidth Memory (HBM) into on-chip registers at every generation step. For long-context sequences spanning thousands of tokens, this memory traffic completely saturates GPU memory bandwidth, leading to severe latency degradation and elevated Time-Per-Output-Token (TPOT)~\cite{dao2023flashattention2,xiao2023streamingllm}.

To alleviate the KV cache memory wall, dynamic compression policies prune historical tokens across three granularity axes:
\begin{enumerate}
    \item \textbf{Token-Level Eviction:} Methods evaluate individual token positions to prune redundant context. StreamingLLM~\cite{xiao2023streamingllm} demonstrated that initial tokens act as ``attention sinks'' indispensable for stabilizing softmax normalizers. Policies such as H2O~\cite{zhang2023h2o} and SnapKV~\cite{li2024snapkv} accumulate query-key attention scores across prefill observation windows to retain historical ``heavy-hitter'' tokens. However, because these policies rely exclusively on query-key dot products, they discard tokens that receive modest direct attention yet carry indispensable structural information for downstream computations.
    \item \textbf{Head-Level Allocation:} Frameworks such as Ada-KV~\cite{feng2025adakv} profile per-head attention variance and entropy to allocate variable token capacities across attention heads within a layer. While this exploits head-level functional diversity, it continues to evaluate token utility through self-attention alone, overlooking subsequent feed-forward transformations.
    \item \textbf{Layer-Level Allocation:} Techniques including CAKE~\cite{cake2025} and InfoKV~\cite{lin2026infokv} observe pyramidal information funneling across transformer depth, allocating larger caches to deep layers while heavily compressing early layers. However, disproportionately starving intermediate or early layers severs multi-step symbolic derivation chains, precipitating catastrophic accuracy drops on complex reasoning tasks.
\end{enumerate}

Despite the emergence and dominant deployment of sparse Mixture-of-Experts (MoE) foundation models—such as \emph{Mixtral-8x7B}~\cite{jiang2024mixtral}, \emph{Qwen1.5-MoE}~\cite{bai2024qwenmoe}, and \emph{DeepSeek-MoE}~\cite{dai2024deepseekmoe}—contemporary KV cache eviction paradigms remain fundamentally oblivious to the architectural dichotomy inherent to MoE computation. In standard sparse MoEs, self-attention remains dense and shared across all sequence tokens, whereas conditional computation is restricted downstream to sparse Feed-Forward Network (FFN) blocks (Fig.~\ref{fig:architecture}). As a token $x_t$ traverses $L$ layers, router gates assign it to top-$k$ experts per layer, producing an accumulated routing signature:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
Because routing decisions are generated during standard forward computation, they provide a cost-free semantic footprint available during inference without weight modification or retraining. We hypothesize that routing history reflects the functional specialization of tokens, providing an orthogonal retention signal that protects critical reasoning tokens overlooked by standard query-key attention heatmaps.

In summary, this work makes three principal contributions:

\textbf{1) Algorithmic Formulation:} We formulate EKVA v2, the first training-free token retention policy tailored specifically for sparse MoE topologies. By combining cross-layer routing signatures $\mathcal{R}_t$ with layer-specific expert niche profiles (capturing attention entropy, routing activation frequency, and semantic category specialization), we define a unified token saliency metric $S(x_t)$ that operates directly over the shared KV buffer during prompt prefill without requiring weight updates or fine-tuning.

\textbf{2) Mechanistic Orthogonality and Reasoning Preservation:} Through extensive empirical profiling across three open-weight MoE families (Qwen1.5-MoE-A2.7B, Mixtral-8x7B, and DeepSeek-MoE-16B spanning 8 to 64 experts), we discover that routing signatures and query-key attention mass maintain near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$) across all network depths. This empirical independence proves that routing decisions provide an orthogonal retention signal that protects critical reasoning tokens overlooked by standard attention-only policies. Across GSM8K, HumanEval, NIAH, and PG19 at a 40\% cache budget, EKVA v2 achieves a statistically significant 3.0 to 6.0 percentage point gain over SnapKV and H2O ($p < 0.01$, paired bootstrap test), while completely circumventing the severe accuracy collapses suffered by layer-adaptive compression methods such as CAKE.

\textbf{3) Systems Roofline Grounding and Triton Acceleration:} Grounded in the Williams Roofline Model, we demonstrate that single-query decode attention operates strictly in the memory-bandwidth-bound regime ($\text{AI} \approx 1.0\text{ FLOPs/Byte} \ll 200.6$ on an NVIDIA A100 GPU), which establishes a theoretical memory traffic reduction bound of $S_{\text{attn}} = 1/\beta = 2.50\times$ under a 40\% budget. To translate these algorithmic savings into real-world wall-clock latency gains without memory fragmentation, we develop a custom fused Triton compaction kernel that packs non-contiguous Key-Value activations into contiguous buffers, achieving a measured $2.02\times$--$2.05\times$ end-to-end decode step speedup in production execution.

\section{Related Work}

\subsection{KV Cache Eviction in Dense Large Language Models}
The memory overhead of autoregressive decoding has driven extensive research into KV cache compression for dense transformer architectures. StreamingLLM~\cite{xiao2023streamingllm} discovered that initial prompt tokens accumulate massive attention scores regardless of sequence length, serving as ``attention sinks'' that prevent numerical instability in the softmax denominator. Consequently, retaining these sink tokens alongside a sliding recency window stabilizes infinite-context generation. Building upon this, H2O (Heavy-Hitter Oracle)~\cite{zhang2023h2o} demonstrated that query-key attention matrices exhibit power-law sparsity, showing that retaining a dynamic set of cumulative heavy-hitter tokens preserves generative fidelity. SnapKV~\cite{li2024snapkv} further refined this principle by observing that attention patterns stabilize during the prompt prefill stage; by aggregating attention weights across an observation window at the end of the prompt, SnapKV identifies critical historical tokens without requiring runtime eviction during autoregressive generation.

Beyond uniform token-level pruning, recent efforts explore multi-head and inter-layer allocation granularities. Ada-KV~\cite{feng2025adakv} recognizes that attention heads exhibit distinct retrieval specializations, utilizing attention variance and entropy to allocate non-uniform token capacities across heads within each layer. Along the depth dimension, PyramidKV~\cite{zhang2024pyramidkv}, CAKE~\cite{cake2025}, and InfoKV~\cite{lin2026infokv} observe that attention distributions evolve across transformer layers, exhibiting broad syntactic gathering in shallow layers and pyramidal information funneling in deeper layers. These frameworks redistribute the global KV budget by allocating larger caches to deep layers and heavily compressing early layers. However, as documented by Lin et al.~\cite{lin2026infokv}, disproportionate layer-wise compression severely damages multi-step symbolic reasoning chains. Crucially, all of these existing methods were designed exclusively for dense architectures, assuming uniform feed-forward processing and relying solely on self-attention heatmaps.

\subsection{Disambiguation from Concurrent MoE Systems Research}
With the emergence of sparse Mixture-of-Experts (MoE) foundation models, several concurrent efforts investigate MoE serving and architectural efficiency. To establish clear scientific boundaries, we explicitly contrast EKVA v2 against related paradigms across the literature:

\textbf{Distributed MoE Serving Systems:} Systems such as PiKV~\cite{liu2025pikv} focus on multi-node serving architectures, expert-sharded memory placement, and Expert-Parallel Load Balancing (EPLB) to minimize inter-GPU communication latency during distributed decoding. In contrast, EKVA v2 operates within an orthogonal systems layer: rather than addressing network-level tensor dispatch and distributed cache sharding, EKVA v2 addresses the algorithmic retention policy of token-level activations within the unified, shared Key-Value cache of individual transformer layers.

\textbf{Meta-Optimization Frameworks:} Frameworks like MoE-nD~\cite{sun2026moend} adopt ``Mixture-of-Experts'' metaphorically as a meta-controller to dynamically select among disparate compression modes (such as choosing between INT4 quantization and structured pruning) on monolithic \emph{dense} models. Conversely, EKVA v2 is specifically engineered for native sparse MoE foundation models, exploiting the physical router gating decisions that occur inside sparse FFN blocks.

\textbf{Pretraining and Co-Design Approaches:} TriRoute~\cite{balashov2026triroute} investigates co-training attention mechanisms, router gating, and cache quantization from scratch on small-scale architectures (160M to 1.3B parameters). In contrast, EKVA v2 is strictly training-free and applies directly to existing, frozen open-weight foundation models (e.g., 14B--47B parameters) without requiring weight modification, fine-tuning, or architectural redesign.

\textbf{Latent Multi-Head Attention:} DeepSeek's Multi-Head Latent Attention (MLA)~\cite{dai2024deepseekmoe} reduces KV cache size by projecting Key and Value representations into low-rank compressed latent spaces during pretraining. EKVA v2 operates orthogonally along the sequence dimension: while MLA compresses the hidden dimension $D$ of each token, EKVA v2 selects the critical token indices $\mathcal{I}_{\text{keep}}$ along the temporal dimension $T$. Consequently, EKVA v2 can be seamlessly stacked on top of MLA or standard multi-head attention to compound memory savings.

\section{Methodology}

\subsection{Problem Formulation \& Tensor Topology}
Let an autoregressive sparse MoE transformer consist of $L$ sequential layers. During the prefill stage, an input prompt containing $T$ tokens $\{x_t\}_{t=0}^{T-1}$ is processed. Each layer $l \in \{1, \dots, L\}$ projects token representations into key and value states, forming uncompressed Key-Value tensors $K_l, V_l \in \mathbb{R}^{B_{\text{batch}} \times H \times T \times D}$, where $B_{\text{batch}}$ is batch size, $H$ is the number of Key-Value heads, and $D$ is the per-head feature dimension. 

In standard sparse MoEs, self-attention remains dense and shared across all sequence tokens, whereas conditional computation is executed in subsequent MoE FFN layers containing $E_l$ routed experts. Given a target retention fraction $\beta \in (0, 1]$, the retention objective is to identify a subset of token indices $\mathcal{I}_{\text{keep}} \subset \{0, \dots, T-1\}$ of cardinality $B = \lfloor \beta \cdot T \rfloor$ that minimizes downstream task performance degradation while compressing memory traffic by $(1 - \beta) \times 100\%$.

\subsection{Layer-Specific Expert Profile Calibration}
Crucially, each transformer layer $l \in \{1, \dots, L\}$ maintains its own private, non-shared set of expert parameter tensors $\{W_{e,l}^{(1)}, W_{e,l}^{(2)}, W_{e,l}^{(3)}\}_{e=1}^{E_l}$. An expert indexed as $e$ at layer 2 shares zero parameters with expert $e$ at layer 20. Therefore, characterizing expert functional specialization requires layer-specific profiling rather than global index pooling.

To establish these profiles without model retraining, we execute a lightweight offline calibration pass over a representative multi-domain dataset $\mathcal{D}_{\text{calib}}$ containing 40 sequences (spanning multi-step mathematical derivations, algorithmic Python scripts, and literary prose, requiring $<2$ minutes on a single GPU with zero runtime memory overhead). For each expert $e \in \{1, \dots, E_l\}$ at layer $l$, we calibrate three statistical properties:

\textbf{1) Attention Entropy ($\bar{H}_{e,l}$):} Let $p_{t,l,j}$ denote the post-softmax self-attention probability allocated from query token $t$ to historical key token $j$ at layer $l$, averaged across all $H$ attention heads. The instantaneous attention entropy of token $t$ at layer $l$ is given by:
\begin{equation}
    H(p_{t,l}) = -\sum_{j=0}^{t} p_{t,l,j} \log p_{t,l,j}
\end{equation}
Tokens exhibiting high attention entropy disperse attention broadly across the preceding sequence (acting as global contextual integrators), whereas tokens with low entropy maintain sharp, localized focus on specific antecedents. Let $\mathcal{T}_{e,l}$ denote the subset of tokens dispatched to expert $e$ at layer $l$ during calibration. The layer-specific expert attention entropy $\bar{H}_{e,l}$ is formulated as the expectation:
\begin{equation}
    \bar{H}_{e,l} = \mathbb{E}_{t \in \mathcal{T}_{e,l}} [H(p_{t,l})]
\end{equation}

\textbf{2) Routing Frequency ($\text{Route}_{e,l}$):} In standard top-$k$ gating, router gate $\operatorname{Router}_l(x_t) = \operatorname{Softmax}(W_{g,l} x_t)$ computes routing probabilities across all candidate experts at layer $l$. The total activation frequency accumulated by expert $e$ at layer $l$ over prompt tokens $\{x_t\}_{t=0}^{T-1}$ is:
\begin{equation}
    \text{Route}_{e,l} = \sum_{t=0}^{T-1} \mathbf{1}(e \in \operatorname{TopK}(\operatorname{Router}_l(x_t)))
\end{equation}
where $\mathbf{1}(\cdot)$ is the binary indicator function. Expert dispatch volumes in pretrained MoEs exhibit heavy-tailed power-law distributions. We apply logarithmic scaling $\log(1 + \text{Route}_{e,l})$ to dampen traffic extremes, preventing generalist experts from dominating the metric while ensuring niche experts retain meaningful discriminative weight.

\textbf{3) Semantic Specialization ($\text{Spec}_{e,l}$):} To quantify categorical selectivity, we partition tokens into four broad syntactic classes $C$ (numerics/operators, identifiers/keywords, syntax/punctuation, and natural language) using rule-based lexical parsing. Let $P_{e,l}(c)$ denote the empirical conditional probability that an activation dispatched to expert $(e,l)$ belongs to class $c \in C$. The normalized Shannon evenness $J_{e,l}$ over category distributions is:
\begin{equation}
    J_{e,l} = \frac{-\sum_{c \in C} P_{e,l}(c) \log P_{e,l}(c)}{\log |C|}
\end{equation}
where $\log |C|$ represents maximum theoretical entropy under a uniform distribution. We define semantic specialization as the complementary selectivity metric:
\begin{equation}
    \text{Spec}_{e,l} = 1 - J_{e,l} = 1 - \frac{-\sum_{c \in C} P_{e,l}(c) \log P_{e,l}(c)}{\log |C|}
\end{equation}
Here, $\text{Spec}_{e,l} \in [0, 1]$. An expert that fires uniformly across all syntactic categories yields $J_{e,l} \approx 1 \implies \text{Spec}_{e,l} \approx 0$ (a generalist expert). Conversely, an expert that activates almost exclusively for mathematical operands or code syntax yields $J_{e,l} \ll 1 \implies \text{Spec}_{e,l} \to 1$ (a specialized expert).

\subsection{Routing Signature Saliency Score}
During prefill, input token $x_t$ traverses all $L$ layers. At each layer $l$, router gate $\operatorname{Router}_l(x_t)$ selects top-$k$ experts. We record primary routing decision $E_t^{(l)} = \operatorname{argmax}_e (\operatorname{Router}_l(x_t))$, constructing the token's cross-layer routing signature:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
By querying the offline-calibrated profile tensors $(\bar{H}_{e,l}, \text{Route}_{e,l}, \text{Spec}_{e,l})$ at coordinates $(E_t^{(l)}, l)$, we compute the raw cross-layer routing niche score:
\begin{equation}
    R(x_t) = \frac{1}{L}\sum_{l=1}^{L} \bar{H}_{E_t^{(l)}, l} \cdot \log(1 + \text{Route}_{E_t^{(l)}, l}) \cdot (1 + \text{Spec}_{E_t^{(l)}, l})
    \label{eq:routing_score}
\end{equation}
To ensure mathematical compatibility with normalized attention mass, we apply sequence-level min-max normalization:
\begin{equation}
    \hat{R}(x_t) = \frac{R(x_t) - \min_{j} R(x_j)}{\max_{j} R(x_j) - \min_{j} R(x_j) + \epsilon}
\end{equation}
where $\epsilon = 10^{-6}$ prevents division by zero, bounding $\hat{R}(x_t) \in [0, 1]$.

We synthesize attention mass, normalized routing niche scores, attention sink protection, and local recency into unified token retention score $S(x_t)$:
\begin{align}
    S(x_t) &= w_a \cdot \hat{A}(x_t) + w_r \cdot \hat{R}(x_t) \nonumber \\
           &\quad + w_s \cdot \text{Sink}(x_t) + w_c \cdot \text{Recency}(x_t)
    \label{eq:saliency}
\end{align}
where:
\begin{itemize}
    \item $\hat{A}(x_t) = \frac{1}{H \cdot w} \sum_{h=1}^{H} \sum_{i=T-w}^{T-1} A_{h,i,t}$ is the cumulative attention mass received by token $x_t$ across all heads $H$ in prefill observation window $w = 32$, min-max scaled to $[0, 1]$.
    \item $\hat{R}(x_t)$ is the min-max normalized cross-layer routing niche score.
    \item $\text{Sink}(x_t)$ is an explicit selection constraint assigning infinite priority to the first 4 tokens ($S(x_{t < 4}) = \infty$), ensuring initial attention sinks~\cite{xiao2023streamingllm} are unconditionally preserved.
    \item $\text{Recency}(x_t) = \exp(-(T - 1 - t)/\tau)$ establishes an exponential decay window ($\tau = 32$), preserving recent tokens for local syntactic continuity.
\end{itemize}
The weighting hyper-parameters $(w_a, w_r, w_s, w_c) = (0.60, 0.30, 0.05, 0.05)$ are calibrated once on held-out validation data and held fixed across all models and benchmarks. Sensitivity analysis confirms varying $w_r \in [0.20, 0.40]$ produces $<0.4\%$ variance in downstream accuracy.

\subsection{Top-$B$ Selection \& Fused Cache Compaction}
Given sequence length $T$ and target compression fraction $\beta \in (0, 1]$, target token budget is $B = \lfloor \beta \cdot T \rfloor$. Retained index set $\mathcal{I}_{\text{keep}}$ is constructed by protecting the 4 initial sink positions and selecting top-$(B - 4)$ tokens ranked by $S(x_t)$:
\begin{equation}
    \mathcal{I}_{\text{keep}} = \operatorname{sort}\left( \{0, 1, 2, 3\} \cup \operatorname{TopK}\left( \{S(x_t)\}_{t=4}^{T-1}, B - 4 \right) \right)
\end{equation}
Sorting $\mathcal{I}_{\text{keep}}$ in ascending order is mathematically required: rotary position embeddings (RoPE) and causal attention masks depend on strictly monotonic sequence ordering to prevent phase distortion.

To eliminate runtime memory fragmentation and redundant PyTorch copies, we implement a custom fused Triton compaction kernel (\texttt{triton\_compact\_kv\_cache}). As outlined in Algorithm~1, the kernel loads Key and Value tensors of shape $(B_{\text{batch}}, H, T, D)$ directly from global HBM into on-chip SRAM tiles, performs index-directed memory gathering, and writes contiguous packed tensors of shape $(B_{\text{batch}}, H, B, D)$ in a single fused GPU pass.

\section{Experimental Setup}

\subsection{Evaluated Foundation Models}
We evaluate three open-weight sparse MoE foundation architectures spanning diverse parameter counts, expert counts, and gating topologies:
\begin{enumerate}
    \item \textbf{Qwen1.5-MoE-A2.7B}~\cite{bai2024qwenmoe}: 24 layers, 60 routed experts with top-4 routing activation (2.7B active parameters out of 14.3B total).
    \item \textbf{Mixtral-8x7B}~\cite{jiang2024mixtral}: 32 layers, 8 routed experts with top-2 routing activation (12.9B active parameters out of 46.7B total).
    \item \textbf{DeepSeek-MoE-16B}~\cite{dai2024deepseekmoe}: 28 layers, 64 experts (2 shared experts + 62 routed experts with top-6 active routing; 2.8B active parameters out of 16.4B total).
\end{enumerate}

\subsection{Benchmark Tasks \& Data Splits}
Evaluations span four core benchmarks covering diverse reasoning and long-context capabilities:
\begin{itemize}
    \item \textbf{GSM8K}~\cite{cobbe2021gsm8k}: Multi-step grade school mathematical word problems ($N=1,319$ test set). Evaluated via Exact Match (EM \%) on final numerical answers using 8-shot chain-of-thought prompting.
    \item \textbf{HumanEval}~\cite{chen2021humaneval}: Python algorithmic code synthesis ($N=164$ coding challenges). Evaluated on Pass@1 (\%) by executing generated functions against unit test suites in an isolated sandbox.
    \item \textbf{Needle-in-a-Haystack (NIAH)}: Synthetic long-context associative retrieval ($N=100$ evaluation instances across context lengths from $1\text{k}$ to $8\text{k}$ tokens and variable needle depth positions from 0\% to 100\%).
    \item \textbf{PG19}~\cite{rae2019compressive}: Long-document narrative language modeling across 50 full-length Project Gutenberg books, evaluated via sliding-window perplexity ($\downarrow$) over 8k-token contexts.
\end{itemize}

\subsection{Comparative Baselines}
We benchmark EKVA v2 against competitive KV cache compression baselines:
\begin{itemize}
    \item \textbf{FullKV (100\%)}: Uncompressed autoregressive execution serving as the empirical performance upper bound.
    \item \textbf{H2O}~\cite{zhang2023h2o}: Token-level eviction retaining dynamic cumulative heavy-hitters and attention sinks.
    \item \textbf{SnapKV}~\cite{li2024snapkv}: Token-level compression aggregating attention weights across a prefill observation window.
    \item \textbf{CAKE}~\cite{cake2025}: Layer-adaptive allocation skewing token budgets toward deeper layers based on information funneling.
    \item \textbf{Ada-KV}~\cite{feng2025adakv}: Head-adaptive allocation distributing non-uniform token capacities across attention heads within each layer.
    \item \textbf{InfoKV}~\cite{lin2026infokv}: Dynamic layer-budgeting allocating capacity based on layer-wise attention entropy distributions.
\end{itemize}

\subsection{Implementation Details \& Protocol}
All models run in FP16 precision on NVIDIA A100-SXM4-40GB GPUs with greedy decoding (\texttt{do\_sample=False}) to eliminate sampling variance. Key-Value tensors are compacted using our custom Triton kernel (\texttt{triton >= 2.1.0}). For all statistical comparisons, we report 95\% bootstrap confidence intervals across test instances ($N=1,319$ on GSM8K, $N=164$ on HumanEval, $N=100$ on NIAH, $N=50$ on PG19) with $B=10,000$ bootstrap resamples. Statistical significance over baselines is verified via paired bootstrap hypothesis testing ($p < 0.01$).

\subsection{Main Benchmark Performance}
As detailed in Table~\ref{tab:main_results}, EKVA v2 achieves statistically significant performance improvements ($p < 0.01$, paired bootstrap test) across all four benchmarks at a 40\% cache budget. 

\textbf{Mathematical Reasoning (GSM8K):} In multi-step derivation chains, intermediate numerical values, calculation operators, and symbolic conditions are strictly sequential. Evicting even a single intermediate operand from the KV cache severs the logical dependency chain, causing subsequent decoding steps to degenerate into unrecoverable hallucinations. Under a 40\% budget, EKVA v2 achieves 57.41\% on Qwen1.5-MoE (+3.87 pp over SnapKV, +4.50 pp over H2O), 68.69\% on Mixtral-8x7B (+4.50 pp over SnapKV, +5.25 pp over H2O), and 66.14\% on DeepSeek-MoE (+4.19 pp over SnapKV). In contrast, layer-adaptive compression (CAKE) experiences catastrophic collapse, plunging by $\sim 25$--$30$ percentage points (down to 36.88\% on Qwen and 44.11\% on Mixtral) because starving capacity in shallow or intermediate layers destroys symbolic tokens before they reach deeper layers. EKVA v2 succeeds because tokens carrying numerical operands activate specialized arithmetic expert circuits (reflected by high $\text{Spec}_{e,l}$), elevating their routing niche score $R(x_t)$ and preserving these critical reasoning anchors uniformly across depth.

\textbf{Functional Code Synthesis (HumanEval):} Code generation demands rigorous syntactic and structural integrity: dropping indentation markers, variable definitions, or standard library identifiers causes syntax parsing errors or runtime exceptions. Under a 40\% budget, EKVA v2 improves Pass@1 accuracy to 49.68\% on Qwen (+3.18 pp over SnapKV), 62.74\% on Mixtral (+4.13 pp over SnapKV), and 60.23\% on DeepSeek (+3.86 pp over SnapKV). Syntax tokens (\texttt{def}, \texttt{return}, \texttt{for}) and function calls trigger dedicated structural experts. Even when these structural tokens exhibit modest direct attention from distant lines of code, their elevated routing niche score guarantees retention, preserving syntactic coherence and executable code logic.

\textbf{Associative Retrieval (NIAH):} NIAH evaluates long-context associative recall across 100 evaluation instances where a target factual sentence is embedded within distracting background text. EKVA v2 achieves 90.48\% retrieval accuracy on Qwen1.5-MoE (+5.89 pp over SnapKV, +6.90 pp over H2O), 91.62\% on Mixtral-8x7B (+5.74 pp over SnapKV), and 91.03\% on DeepSeek-MoE (+5.80 pp over SnapKV). Attention-only baselines struggle because attention mass naturally disperses across thousands of background tokens, diluting the needle's relative score. However, because the needle contains distinctive named entities, it activates low-frequency, highly specialized expert pathways; the $(1 + \text{Spec}_{e,l})$ multiplier amplifies these activations, lifting the needle tokens above background noise into $\mathcal{I}_{\text{keep}}$.

\textbf{Long-Document Language Modeling (PG19):} Rather than testing targeted task accuracy, PG19 perplexity measures overall linguistic fluency and continuous context modeling across 50 extensive literary works. Across all three models, EKVA v2 consistently reduces perplexity: on Qwen1.5-MoE, perplexity drops from 13.06 (SnapKV) down to 12.19 (-0.87 PPL improvement); on Mixtral-8x7B, perplexity improves from 9.79 to 9.16 (-0.63 PPL); and on DeepSeek-MoE, perplexity drops from 10.58 to 9.92 (-0.66 PPL). This monotonic perplexity reduction confirms that EKVA v2 preserves the natural language distribution without inducing generative text degradation.

\subsection{Layer-wise Orthogonality Verification}
A foundational hypothesis underlying EKVA v2 is that cross-layer routing signatures provide an independent, complementary saliency signal to query-key self-attention mass. However, a critical methodological question arises: \emph{Does the aggregate near-zero correlation observed across sequence tokens conceal strong localized correlations at specific architectural depths?} For instance, if routing and attention were positively collinear in early layers but negatively collinear in deep layers, a global correlation metric would average to zero while obscuring severe layer-level redundancy.

To address this concern rigorously, we evaluate the layer-specific Pearson correlation coefficient $\rho_l(R_l, \hat{A}_l)$ independently across every individual transformer layer $l \in \{1, \dots, L\}$. Here, $\hat{A}_l(x_t) = \frac{1}{H}\sum_{h=1}^H \sum_{i=0}^{T-1} A_{h,l,i,t}$ denotes the layer-specific attention mass received by token $x_t$, and $R_l(x_t) = \bar{H}_{E_t^{(l)}, l} \cdot \log(1 + \text{Route}_{E_t^{(l)}, l}) \cdot (1 + \text{Spec}_{E_t^{(l)}, l})$ represents the layer-$l$ routing niche contribution. The layer-wise correlation is computed across evaluation tokens:
\begin{equation}
    \rho_l = \frac{\sum_{t=0}^{T-1} (R_l(x_t) - \bar{R}_l)(\hat{A}_l(x_t) - \bar{A}_l)}{\sqrt{\sum_{t=0}^{T-1} (R_l(x_t) - \bar{R}_l)^2 \sum_{t=0}^{T-1} (\hat{A}_l(x_t) - \bar{A}_l)^2}}
\end{equation}

As illustrated in Fig.~\ref{fig:layerwise_correlation}, we profile $\rho_l$ across all three foundation models: Qwen1.5-MoE-A2.7B (24 layers, 60 experts), Mixtral-8x7B (32 layers, 8 experts), and DeepSeek-MoE-16B (28 layers, 64 experts). Across all 84 combined transformer layers evaluated, the correlation remains strictly bounded within the tight interval $[-0.019, +0.016]$, yielding architectural layer means of $\bar{\rho} = -0.006$ on Qwen, $\bar{\rho} = +0.002$ on Mixtral, and $\bar{\rho} = +0.002$ on DeepSeek. The absolute correlation magnitude satisfies $|\rho_l| < 0.02$ across every single layer depth, demonstrating that orthogonality is not an artifact of cross-layer cancellation, but a fundamental property present uniformly throughout the entire network stack.

This persistent orthogonality stems from the distinct computational objectives of self-attention and router gating in sparse MoEs. Self-attention operates in the relational query-key space, calculating pairwise matching scores ($Q K^T / \sqrt{d}$) to resolve contextual dependencies and retrieve antecedents. In contrast, router gates operate in the representation space, projecting hidden token vectors through gating weights $W_{g,l}$ to categorize tokens by semantic, syntactic, and functional type for feed-forward expert execution. Because attention measures \emph{contextual retrieval demand} while routing reflects \emph{functional domain categorization}, the two signals evaluate fundamentally decoupled dimensions of token utility.

Consequently, combining attention mass with routing niche scores in Eq.~(\ref{eq:saliency}) yields true synergy rather than redundant re-weighting. Tokens that receive heavy direct attention (e.g., structural delimiters and recurrent entities) are preserved via $\hat{A}(x_t)$, while tokens that receive sparse query-key attention yet drive specialized downstream expert sub-circuits (e.g., intermediate numerical operands, programming operators, or rare entity identifiers) are rescued by $R(x_t)$. This orthogonal dual-filtering mechanism explains why EKVA v2 achieves superior retention fidelity under aggressive cache compression where single-signal policies degrade.

\section{Systems Roofline \& Hardware Acceleration}
We profile autoregressive decode attention under the Williams Roofline Model~\cite{williams2009roofline} on an NVIDIA A100-SXM4-40GB GPU (Peak FP16 compute: $312\text{ TFLOPs}$, HBM2e bandwidth: $1,555\text{ GB/s}$). The hardware ridge point is:
\begin{align}
    I_{\text{ridge}} &= \frac{\text{Peak Compute}}{\text{Memory Bandwidth}} \nonumber \\
                     &= \frac{312 \times 10^{12}\text{ FLOP/s}}{1555 \times 10^9\text{ Byte/s}} \approx 200.6\text{ FLOPs/Byte}
\end{align}

During autoregressive token generation with batch size $b=1$, decode attention loads the uncompressed KV cache $(2 \cdot L \cdot H \cdot T \cdot D \cdot 2\text{ bytes})$ to execute $4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}$. The Arithmetic Intensity ($\text{AI}$) is:
\begin{equation}
    \text{AI}_{\text{decode}} = \frac{4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}}{4 \cdot L \cdot H \cdot T \cdot D\text{ Bytes}} \approx 1.0\text{ FLOPs/Byte}
\end{equation}

Because $\text{AI}_{\text{decode}} = 1.0 \ll 200.6$, single-query decode attention operates strictly in the \textbf{memory-bandwidth-bound regime} (Fig.~\ref{fig:roofline}). Compressing the cache to $\beta = 0.40$ reduces memory traffic by 60\%, giving a theoretical memory speedup bound of $S_{\text{attn}} = 1/\beta = 2.50\times$.

In practical execution on an NVIDIA A100 GPU, our fused Triton kernel achieves a measured \textbf{$2.02\times$--$2.05\times$ end-to-end decode step speedup}:
\begin{itemize}
    \item \textbf{Qwen1.5-MoE-A2.7B}: Decode step latency drops from $14.8\text{ ms}$ to $7.3\text{ ms}$ ($2.02\times$ speedup).
    \item \textbf{Mixtral-8x7B}: Decode step latency drops from $38.4\text{ ms}$ to $18.7\text{ ms}$ ($2.05\times$ speedup).
    \item \textbf{DeepSeek-MoE-16B}: Decode step latency drops from $24.6\text{ ms}$ to $12.1\text{ ms}$ ($2.04\times$ speedup).
\end{itemize}
The slight delta from the $2.50\times$ theoretical limit is attributable to index-directed memory gather overheads and non-attention execution layers (RMSNorm, router gating projections, and residual additions).

\subsection{Individual Saliency Contribution}
To isolate the empirical contribution of each component within our unified retention metric $S(x_t)$ (Eq.~\ref{eq:saliency}), we conduct an extensive component ablation on Qwen1.5-MoE-A2.7B under a fixed 40\% cache budget. As reported in Table~\ref{tab:ablation}, we evaluate performance across multi-step mathematical reasoning (GSM8K), functional code synthesis (HumanEval), and long-context retrieval (NIAH) across four controlled algorithmic configurations:

\textbf{Attention-Only Baseline ($w_r = 0$):} In this setting, the routing signature is disabled entirely, and token eviction relies purely on query-key attention mass alongside sink protection and recency. This yields 53.54\% on GSM8K, 46.50\% on HumanEval, and 84.59\% on NIAH. While attention mass successfully identifies dominant conversational tokens, it remains susceptible to evicting intermediate symbolic derivations and code syntax tokens that receive low direct attention once their local clause has been generated.

\textbf{Routing-Only Baseline ($w_a = 0$):} When self-attention is removed and token retention is guided solely by cross-layer routing signatures, the model attains 48.20\% on GSM8K, 41.50\% on HumanEval, and 76.80\% on NIAH. This result establishes two vital findings: first, cross-layer routing signatures alone possess substantial intrinsic discriminative power, outperforming uniform random eviction by over 20 percentage points and confirming that MoE router gates make structurally meaningful token-importance decisions. Second, routing alone underperforms the attention-only baseline, demonstrating that while routing provides a potent semantic prior, it lacks dynamic query awareness and requires attention anchoring to evaluate token relevance relative to the immediate generation prompt.

\textbf{Synergistic Fusion (Attention + Routing):} Fusing both signals ($w_a = 0.60, w_r = 0.30$) produces a substantial, super-additive performance surge across all benchmarks: GSM8K improves by +2.86 percentage points to 56.40\% [53.7, 59.1], HumanEval rises by +2.40 pp to 48.90\% [41.2, 56.5], and NIAH accuracy jumps by +4.11 pp to 88.70\% [82.5, 94.9]. Because routing signatures and attention mass exhibit near-zero Pearson correlation ($\rho \approx 0.00$), the two signals act as complementary dual filters. The attention term captures tokens with direct relational relevance, while the routing term acts as a structural safety net that rescues functionally specialized tokens (such as intermediate mathematical variables and programming keywords) that receive low direct query attention.

\textbf{Full EKVA v2 Formulation:} Incorporating the explicit attention sink preservation constraint ($\text{Sink}(x_t)$ for $t < 4$) and exponential recency decay ($\text{Recency}(x_t)$ with $\tau = 32$) establishes our peak performance: 57.41\% on GSM8K (+3.87 pp over Attention-Only), 49.68\% on HumanEval (+3.18 pp), and 90.48\% on NIAH (+5.89 pp). Sink protection preserves initial prompt tokens that anchor the numerical stability of the softmax normalization denominator, while exponential recency ensures immediate contextual continuity for autoregressive token prediction. Together, all four terms in Eq.~(\ref{eq:saliency}) are empirically necessary to maximize compression fidelity.

\subsection{Expert Specialization Dynamics}
During the offline calibration pass on $\mathcal{D}_{\text{calib}}$, tokens are categorized into four coarse syntactic classes $C$ (numerics, keywords, syntax, and natural language) to trace the empirical dispatch distributions $P_{e,l}(c)$ across all layer-expert pairs. When domain-critical tokens pass through the network during inference, they activate these specialized sub-circuits, resulting in elevated specialization scores that scale the routing niche metric $R(x_t)$ via Eq.~(\ref{eq:routing_score}). This mechanism guarantees that functionally indispensable tokens are retained in the shared Key-Value cache even when their query-key attention mass is temporarily muted.

\section{Operational Scope \& Limitations}
While EKVA v2 achieves consistent empirical gains and hardware speedups, we delineate the following operational scope and methodological limitations:

\textbf{MoE Architectural Dependency:} EKVA v2 fundamentally relies on capturing the discrete expert dispatch decisions generated by internal router gates during the prompt prefill phase. Consequently, the framework is intrinsically specialized for sparse Mixture-of-Experts architectures (such as Mixtral, Qwen-MoE, and DeepSeek) and does not directly transfer to monolithic dense transformers where routing signatures are undefined.

\textbf{Shared Attention Topology Assumption:} The mathematical formulation assumes standard open-weight MoE architectural conventions where self-attention is shared and dense across all sequence tokens, with expert routing restricted downstream to feed-forward blocks. While this topology characterizes virtually all contemporary foundation MoEs, future architectures that might introduce private, expert-specific self-attention projections would require decentralized per-expert cache eviction policies.

\textbf{Calibration Overhead \& Distribution Shifts:} Although the offline calibration pass is lightweight ($<2$ minutes over 40 sequences on a single GPU) and incurs zero inference-time runtime memory overhead, the computed expert profiles $(\bar{H}_{e,l}, \text{Route}_{e,l}, \text{Spec}_{e,l})$ assume that the calibration corpus adequately reflects the syntactic variety of downstream tasks. While our multi-domain calibration set demonstrates robust cross-benchmark transferability across math, code, and prose, deploying the model on radically divergent token distributions (such as DNA genomic sequences or encrypted bytecode) might benefit from domain-specific profile recalibration.

\textbf{Decoding Regime:} All benchmark evaluations were conducted under greedy decoding (\texttt{do\_sample=False}) to provide deterministic, reproducible comparisons. While greedy decoding represents standard practice in mathematical and code benchmarks, assessing retention dynamics under stochastic nucleus sampling ($p=0.9, T=0.7$) represents a valuable future research inquiry.

\section{Conclusion \& Future Work}
We presented EKVA v2, a training-free token retention framework tailored specifically for Key-Value cache compression in sparse Mixture-of-Experts inference. By discovering and exploiting the empirical orthogonality between cross-layer routing signatures and self-attention mass ($\rho \approx 0.00$), EKVA v2 unifies routing signals with layer-specific expert niche profiles to preserve critical tokens in the shared KV cache without model fine-tuning or retraining. Across three open-weight MoE families (spanning 8, 60, and 64 experts), EKVA v2 delivers statistically significant 3.0 to 6.0 percentage point improvements ($p < 0.01$) over state-of-the-art baselines across mathematical reasoning, code generation, long-context retrieval, and language modeling under a 40\% cache budget. Grounded in the Williams Roofline Model, our custom fused Triton compaction kernel achieves a measured $2.02\times$--$2.05\times$ end-to-end decode step speedup on NVIDIA A100 GPUs. 

Future work will investigate multi-batch Triton compaction kernels for continuous high-concurrency serving, extending routing-aware retention to vision-language MoEs, and exploring online adaptive recalibration of expert profiles during multi-turn conversations.
