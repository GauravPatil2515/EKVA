\begin{abstract}
During long-context autoregressive inference in Large Language Models (LLMs), the Key-Value (KV) cache memory footprint is the dominant performance bottleneck. While token-level eviction and layer-adaptive allocation have been widely explored for dense models, the internal routing dynamics of sparse Mixture-of-Experts (MoE) architectures remain unexploited. In standard sparse MoEs (\emph{Mixtral-8x7B}, \emph{Qwen1.5-MoE}, \emph{DeepSeek-MoE}), self-attention is shared and dense, while sparse routing occurs downstream in the Feed-Forward Network (FFN) blocks. Consequently, each token accumulates an internal cross-layer \emph{routing signature} $\mathcal{R}_t = \{E_t^{(1)}, \dots, E_t^{(L)}\}$ during standard forward computation. In this paper, we propose \textbf{EKVA v2}, a training-free token retention framework that leverages cross-layer routing signatures and layer-specific expert niche profiles (entropy, activation frequency, and specialization) to govern eviction in the shared KV cache. Across three MoE families (8, 60, and 64 experts), routing scores exhibit near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$) with self-attention mass across all layers, demonstrating that routing captures an independent, complementary dimension of token importance. Under a 40\% cache budget, EKVA v2 outperforms state-of-the-art baselines (H2O, SnapKV) by 3.0 to 6.0 percentage points ($p < 0.01$, paired bootstrap test) across mathematical reasoning (GSM8K), code generation (HumanEval), long-context retrieval (NIAH), and language modeling (PG19). Furthermore, a fused Triton compaction kernel delivers a \textbf{$2.02\times$--$2.05\times$ decode speedup} on NVIDIA A100 GPUs.
\end{abstract}

% I. INTRODUCTION
% -------------------------------------------------------------------------
\section{Introduction}
Autoregressive decoding in modern Large Language Models (LLMs) requires storing Key-Value (KV) activations for all context tokens in High-Bandwidth Memory (HBM). As sequence lengths grow to tens of thousands of tokens, loading large KV tensors at every decoding step saturates GPU memory bandwidth, leading to severe throughput degradation and increased Time-Per-Output-Token (TPOT)~\cite{dao2023flashattention2,xiao2023streamingllm}.

Dynamic KV cache compression methods reduce this memory traffic across three main granularity axes:
\begin{enumerate}
    \item \textbf{Token-Level Eviction}: Token-level methods evaluate individual position saliency to dynamically prune redundant tokens from the sequence. StreamingLLM~\cite{xiao2023streamingllm} discovered that initial prompt tokens serve as persistent ``attention sinks'' essential for maintaining softmax numerical stability, requiring their unconditional retention. Building on this, policies such as H2O~\cite{zhang2023h2o} and SnapKV~\cite{li2024snapkv} accumulate query-key attention scores across prefill observation windows to identify historical ``heavy-hitter'' tokens that receive sustained cross-sequence focus. Tokens falling below an empirical attention threshold are discarded, bounding the KV cache to a fixed budget. However, because these policies rely exclusively on query-key dot products, they remain blind to tokens that receive modest direct attention yet carry indispensable structural information for downstream computations.
    \item \textbf{Head-Level Allocation}: Rather than enforcing uniform capacity across all attention heads within a layer, head-level budgeting exploits the functional diversity among multi-head projections. Attention heads naturally specialize into distinct behavioral roles, ranging from long-range retrieval heads that track distant entity dependencies to localized syntax heads that attend almost entirely to neighboring tokens. Frameworks such as Ada-KV~\cite{feng2025adakv} adaptively profile per-head attention variance and entropy to allocate non-uniform token quotas, pruning low-utility heads more aggressively. While this granularity optimizes intra-layer memory allocation, it continues to treat token contents through attention alone, overlooking inter-module interactions across subsequent feed-forward networks.
    \item \textbf{Layer-Level Allocation}: Layer-wise approaches redistribute the total memory budget across transformer depth based on macroscopic information flow. Techniques including CAKE~\cite{cake2025} and InfoKV~\cite{lin2026infokv} observe that early transformer layers engage in broad contextual gathering, whereas intermediate and deep layers exhibit pyramidal information funneling. Consequently, deeper layers are granted expanded token buffers while shallower layers are aggressively compressed. Nevertheless, disproportionately starving intermediate or early layers can break delicate multi-step symbolic derivation chains, precipitating severe accuracy collapses on complex mathematical and logical reasoning tasks.
\end{enumerate}

Despite the rapid ascension and widespread deployment of sparse Mixture-of-Experts (MoE) foundation models—such as \emph{Mixtral-8x7B}~\cite{jiang2024mixtral}, \emph{Qwen1.5-MoE}~\cite{bai2024qwenmoe}, and \emph{DeepSeek-MoE}~\cite{dai2024deepseekmoe}—contemporary KV cache eviction paradigms remain fundamentally oblivious to the architectural dichotomy inherent to MoE computation. Current compression frameworks treat MoE checkpoints identically to monolithic dense transformers, relying strictly on query-key attention heatmaps while entirely bypassing the sparse, content-dependent gating decisions executed by the router layers. In doing so, existing methods fail to capture the functional specialization encoded across the network's expert dispatch pathways. Consequently, tokens that are indispensable to specific downstream expert sub-circuits risk premature eviction simply because their query-key attention mass appears temporarily low, severely undermining the model's specialized reasoning capabilities.

\subsection{Architectural Insight \& Motivation}
In standard sparse MoEs, self-attention remains shared across all tokens, while conditional routing occurs strictly in subsequent FFN blocks (Fig.~\ref{fig:architecture}). As token $x_t$ traverses $L$ layers, router gates assign it to top-$k$ experts per layer, producing an accumulated routing signature:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
Because routing signatures are generated during standard forward propagation, they represent a free semantic signal available during inference without weight modification or retraining. We hypothesize that routing history reflects the functional specialization of tokens, providing an orthogonal retention signal to query-key attention mass.

\subsection{Key Contributions}
In summary, this work addresses the KV cache memory wall in sparse Mixture-of-Experts inference through three principal contributions:

\emph{1) Algorithmic Formulation:} We formulate EKVA v2, the first training-free token retention policy tailored specifically to sparse MoE topologies. By extracting cross-layer routing signatures $\mathcal{R}_t$ during prompt prefill and coupling them with layer-specific expert niche profiles (capturing attention entropy, routing activation frequency, and semantic category specialization), we define a unified token saliency metric $S(x_t)$ that operates directly over the shared KV buffer without modifying model weights or requiring fine-tuning.

\emph{2) Mechanistic Orthogonality and Reasoning Preservation:} Through extensive empirical profiling across three open-weight MoE families (Qwen1.5-MoE-A2.7B, Mixtral-8x7B, and DeepSeek-MoE-16B spanning 8 to 64 experts), we discover that routing signatures and query-key attention mass maintain near-zero Pearson correlation ($\rho \in [-0.006, +0.002]$) across all network depths. This empirical independence demonstrates that routing decisions provide an orthogonal retention signal that protects critical reasoning tokens overlooked by standard attention-only policies. Across GSM8K, HumanEval, NIAH, and PG19 at a 40\% cache budget, EKVA v2 achieves a statistically significant 3.0 to 6.0 percentage point gain over SnapKV and H2O ($p < 0.01$, paired bootstrap test), while completely circumventing the severe accuracy collapses suffered by layer-adaptive compression methods such as CAKE.

\emph{3) Systems Roofline Grounding and Triton Acceleration:} Grounded in the Williams Roofline Model, we demonstrate that single-query decode attention operates strictly in the memory-bandwidth-bound regime ($\text{AI} \approx 1.0\text{ FLOPs/Byte} \ll 200.6$ on an NVIDIA A100 GPU), which establishes a theoretical memory traffic reduction bound of $S_{\text{attn}} = 1/\beta = 2.50\times$ under a 40\% budget. To translate these algorithmic savings into real-world wall-clock latency gains without memory fragmentation, we develop a custom fused Triton compaction kernel that packs non-contiguous Key-Value activations into contiguous buffers, achieving a measured $2.02\times$--$2.05\times$ end-to-end decode step speedup in production execution.

% II. RELATED WORK

\section{Related Work}

\subsection{KV Cache Eviction in Dense Large Language Models}
The memory overhead of autoregressive decoding has driven extensive research into KV cache compression for dense transformer architectures. StreamingLLM~\cite{xiao2023streamingllm} discovered that initial prompt tokens accumulate massive attention scores regardless of sequence length, serving as ``attention sinks'' that prevent numerical instability in the softmax denominator. Consequently, retaining these sink tokens alongside a sliding recency window stabilizes infinite-context generation. Building upon this, H2O (Heavy-Hitter Oracle)~\cite{zhang2023h2o} demonstrated that query-key attention matrices exhibit power-law sparsity, showing that retaining a dynamic set of cumulative heavy-hitter tokens preserves generative fidelity. SnapKV~\cite{li2024snapkv} further refined this principle by observing that attention patterns stabilize during the prompt prefill stage; by aggregating attention weights across an observation window at the end of the prompt, SnapKV identifies critical historical tokens without requiring runtime eviction during autoregressive generation.

Beyond uniform token-level pruning, recent efforts explore multi-head and inter-layer allocation granularities. Ada-KV~\cite{feng2025adakv} recognizes that attention heads exhibit distinct retrieval specializations, utilizing attention variance and entropy to allocate non-uniform token capacities across heads within each layer. Along the depth dimension, PyramidKV~\cite{zhang2024pyramidkv}, CAKE~\cite{cake2025}, and InfoKV~\cite{lin2026infokv} observe that attention distributions evolve across transformer layers, exhibiting broad syntactic gathering in shallow layers and pyramidal information funneling in deeper layers. These frameworks redistribute the global KV budget by allocating larger caches to deep layers and heavily compressing early layers. However, as documented by Lin et al.~\cite{lin2026infokv}, disproportionate layer-wise compression severely damages multi-step symbolic reasoning chains. Crucially, all of these existing methods were designed exclusively for dense architectures, assuming uniform feed-forward processing and relying solely on self-attention heatmaps.

\subsection{Disambiguation from Concurrent MoE Systems Research}
With the emergence of sparse Mixture-of-Experts (MoE) foundation models, several concurrent efforts investigate MoE serving and architectural efficiency. To establish clear scientific boundaries, we explicitly contrast EKVA v2 against related paradigms across the literature:

\textbf{Distributed MoE Serving Systems:} Systems such as PiKV~\cite{liu2025pikv} focus on multi-node serving architectures, expert-sharded memory placement, and Expert-Parallel Load Balancing (EPLB) to minimize inter-GPU communication latency during distributed decoding. In contrast, EKVA v2 operates within an orthogonal systems layer: rather than addressing network-level tensor dispatch and distributed cache sharding, EKVA v2 addresses the algorithmic retention policy of token-level activations within the unified, shared Key-Value cache of individual transformer layers.

\textbf{Meta-Optimization Frameworks:} Frameworks like MoE-nD~\cite{sun2026moend} adopt ``Mixture-of-Experts'' metaphorically as a meta-controller to dynamically select among disparate compression modes (such as choosing between INT4 quantization and structured pruning) on monolithic \emph{dense} models. Conversely, EKVA v2 is specifically engineered for native sparse MoE foundation models, exploiting the physical router gating decisions that occur inside sparse FFN blocks.

\textbf{Pretraining and Co-Design Approaches:} TriRoute~\cite{balashov2026triroute} investigates co-training attention mechanisms, router gating, and cache quantization from scratch on small-scale architectures (160M to 1.3B parameters). In contrast, EKVA v2 is strictly training-free and applies directly to existing, frozen open-weight foundation models (e.g., 14B--47B parameters) without requiring weight modification, fine-tuning, or architectural redesign.

\textbf{Latent Multi-Head Attention:} DeepSeek's Multi-Head Latent Attention (MLA)~\cite{dai2024deepseekmoe} reduces KV cache size by projecting Key and Value representations into low-rank compressed latent spaces during pretraining. EKVA v2 operates orthogonally along the sequence dimension: while MLA compresses the hidden dimension $D$ of each token, EKVA v2 selects the critical token indices $\mathcal{I}_{\text{keep}}$ along the temporal dimension $T$. Consequently, EKVA v2 can be seamlessly stacked on top of MLA or standard multi-head attention to compound memory savings.

\section{Methodology}

\subsection{Expert Profile Calibration}
Sparse MoE architectures structure each transformer block by pairing a dense self-attention module with a sparse MoE Feed-Forward Network (FFN). Crucially, each transformer layer $l \in \{1, \dots, L\}$ maintains its own private, non-shared set of expert weight tensors $\{W_{e,l}^{(1)}, W_{e,l}^{(2)}, W_{e,l}^{(3)}\}_{e=1}^{E_l}$. An expert indexed as $e=3$ at layer 2 shares zero architectural or parametric relationship with expert $e=3$ at layer 20. Consequently, characterizing expert functional specialization requires layer-specific profiling rather than global index pooling.

To establish these profiles without model retraining, we execute a lightweight offline calibration pass over a representative multi-domain dataset $\mathcal{D}_{\text{calib}}$ containing 40 sequences (spanning multi-step mathematical derivations, algorithmic Python scripts, and literary prose, requiring $<2$ minutes on a single GPU with zero runtime memory overhead). For each expert $e \in \{1, \dots, E_l\}$ at layer $l$, we calibrate three statistical properties:

\textbf{1) Attention Entropy ($\bar{H}_{e,l}$):} Let $p_{t,l,j}$ denote the post-softmax self-attention probability allocated from query token $t$ to historical key token $j$ at layer $l$, averaged across all $H$ attention heads. The instantaneous attention entropy of token $t$ at layer $l$ is given by:
\begin{equation}
    H(p_{t,l}) = -\sum_{j=0}^{t} p_{t,l,j} \log p_{t,l,j}
\end{equation}
Tokens exhibiting high attention entropy disperse attention broadly across the preceding sequence (acting as global contextual integrators), whereas tokens with low entropy maintain sharp, localized focus on specific antecedents. Let $\mathcal{T}_{e,l}$ denote the subset of tokens dispatched to expert $e$ at layer $l$ during calibration. The layer-specific expert attention entropy $\bar{H}_{e,l}$ is formulated as the expectation:
\begin{equation}
    \bar{H}_{e,l} = \mathbb{E}_{t \in \mathcal{T}_{e,l}} [H(p_{t,l})]
\end{equation}
This scalar quantifies the contextual dispersion characteristic of the tokens that preferentially activate expert $(e, l)$.

\textbf{2) Routing Frequency ($\text{Route}_{e,l}$):} In standard top-$k$ gating, router gate $\operatorname{Router}_l(x_t) = \operatorname{Softmax}(W_{g,l} x_t)$ computes routing probabilities across all candidate experts at layer $l$. The total activation frequency accumulated by expert $e$ at layer $l$ over prompt tokens $\{x_t\}_{t=0}^{T-1}$ is:
\begin{equation}
    \text{Route}_{e,l} = \sum_{t=0}^{T-1} \mathbf{1}(e \in \operatorname{TopK}(\operatorname{Router}_l(x_t)))
\end{equation}
where $\mathbf{1}(\cdot)$ is the binary indicator function returning 1 if expert $e$ is among the top-$k$ selected candidates and 0 otherwise. Expert dispatch volumes in pretrained MoEs exhibit heavy-tailed power-law distributions, where a small subset of ``generalist'' experts process disproportionately large token shares while domain-specific experts fire selectively. In our retention metric, we apply logarithmic scaling $\log(1 + \text{Route}_{e,l})$ to dampen traffic extremes, preventing generalist experts from dominating the metric while ensuring niche experts retain meaningful discriminative weight.

\textbf{3) Semantic Specialization ($\text{Spec}_{e,l}$):} To quantify categorical selectivity, we partition tokens into four broad syntactic classes $C$ (numerics/operators, identifiers/keywords, syntax/punctuation, and natural language) using rule-based lexical parsing. Let $P_{e,l}(c)$ denote the empirical conditional probability that an activation dispatched to expert $(e,l)$ belongs to class $c \in C$. The normalized Shannon evenness $J_{e,l}$ over category distributions is:
\begin{equation}
    J_{e,l} = \frac{-\sum_{c \in C} P_{e,l}(c) \log P_{e,l}(c)}{\log |C|}
\end{equation}
where $\log |C|$ represents maximum theoretical entropy under a uniform distribution. We define semantic specialization as the complementary selectivity metric:
\begin{equation}
    \text{Spec}_{e,l} = 1 - J_{e,l} = 1 - \frac{-\sum_{c \in C} P_{e,l}(c) \log P_{e,l}(c)}{\log |C|}
\end{equation}
Here, $\text{Spec}_{e,l} \in [0, 1]$. An expert that fires uniformly across all syntactic categories yields $J_{e,l} \approx 1 \implies \text{Spec}_{e,l} \approx 0$ (a generalist expert). Conversely, an expert that activates almost exclusively for mathematical operands or code syntax yields $J_{e,l} \ll 1 \implies \text{Spec}_{e,l} \to 1$ (a specialized expert).

\subsection{Routing Signature Saliency Score}
During the forward prefill phase of inference, an input token $x_t$ traverses all $L$ layers of the transformer. At each layer $l$, the router gate dispatches $x_t$ to top-$k$ experts. We record the primary routing decision $E_t^{(l)} = \operatorname{argmax}_e (\operatorname{Router}_l(x_t))$, constructing the token's accumulated cross-layer routing signature:
\begin{equation}
    \mathcal{R}_t = \{ E_t^{(1)}, E_t^{(2)}, \dots, E_t^{(L)} \}
\end{equation}
By querying the offline-calibrated profile tensors $(\bar{H}_{e,l}, \text{Route}_{e,l}, \text{Spec}_{e,l})$ at the exact layer-expert coordinates $(E_t^{(l)}, l)$ visited by token $x_t$, we formulate the cross-layer routing niche score $R(x_t)$ as:
\begin{equation}
    R(x_t) = \frac{1}{L}\sum_{l=1}^{L} \bar{H}_{E_t^{(l)}, l} \cdot \log(1 + \text{Route}_{E_t^{(l)}, l}) \cdot (1 + \text{Spec}_{E_t^{(l)}, l})
    \label{eq:routing_score}
\end{equation}
In Eq.~(\ref{eq:routing_score}), the outer factor $1/L$ normalizes the score across transformer depth. The inner multiplicative formulation jointly weights contextual dispersion ($\bar{H}$), log-frequency, and a specialization amplifier $(1 + \text{Spec}) \in [1, 2]$. If a token consistently engages specialized expert sub-circuits across multiple layers, its routing niche score $R(x_t)$ escalates significantly, providing an architectural signal that this token carries indispensable functional utility.

To construct the global token retention policy, we synthesize attention mass, routing niche scores, attention sink protection, and local recency into a unified retention score $S(x_t)$:
\begin{align}
    S(x_t) &= w_a \cdot \hat{A}(x_t) + w_r \cdot R(x_t) \nonumber \\
           &\quad + w_s \cdot \text{Sink}(x_t) + w_c \cdot \text{Recency}(x_t)
    \label{eq:saliency}
\end{align}
where each constituent term is defined as follows:
\begin{itemize}
    \item $\hat{A}(x_t) = \frac{1}{H} \sum_{h=1}^{H} \sum_{i=0}^{T-1} A_{h,i,t}$ is the cumulative attention mass received by token $x_t$ across all attention heads $H$, normalized to the range $[0, 1]$.
    \item $R(x_t)$ is the normalized cross-layer routing niche score from Eq.~(\ref{eq:routing_score}).
    \item $\text{Sink}(x_t)$ implements an explicit retention constraint assigning infinite priority to the initial 4 prompt tokens ($S(x_{t < 4}) = \infty$), ensuring that initial attention sinks~\cite{xiao2023streamingllm} are unconditionally preserved to prevent softmax divergence.
    \item $\text{Recency}(x_t) = \exp(-(T - 1 - t)/\tau)$ establishes an exponential recency decay window with time constant $\tau = 32$, guaranteeing that prompt-final tokens are preserved to maintain local syntactic continuity during autoregressive generation.
\end{itemize}
The weighting hyper-parameters $(w_a, w_r, w_s, w_c) = (0.60, 0.30, 0.05, 0.05)$ are calibrated once on held-out validation sequences and held fixed across all models and benchmarks. Sensitivity analysis confirms that varying $w_r \in [0.20, 0.40]$ produces $<0.4\%$ variance in downstream accuracy.

\subsection{Top-$B$ Selection \& Fused Cache Compaction}
Given sequence length $T$ and target compression fraction $\beta \in (0, 1]$, the target token budget is $B = \lfloor \beta \cdot T \rfloor$. The retained index set $\mathcal{I}_{\text{keep}}$ is assembled by reserving the 4 initial sink positions and selecting the top-$(B - 4)$ tokens ranked by unified saliency $S(x_t)$:
\begin{equation}
    \mathcal{I}_{\text{keep}} = \operatorname{sort}\left( \{0, 1, 2, 3\} \cup \operatorname{TopK}\left( \{S(x_t)\}_{t=4}^{T-1}, B - 4 \right) \right)
\end{equation}
Crucially, sorting the index set $\mathcal{I}_{\text{keep}}$ in ascending order is mathematically required: rotary position embeddings (RoPE) and causal attention masks depend on strictly monotonic sequence ordering to prevent phase distortion.

During autoregressive generation, managing a non-contiguous KV cache via standard PyTorch indexing (\texttt{pkv[:, :, indices, :]}) induces severe memory fragmentation, triggers redundant tensor allocations, and launches multiple auxiliary CUDA kernels. To eliminate this runtime overhead, we implement a custom fused Triton compaction kernel (\texttt{triton\_compact\_kv\_cache}). As outlined in Algorithm~1, the kernel loads Key and Value tensors of shape $(B_{\text{batch}}, H, T, D)$ directly from global HBM into on-chip SRAM tiles, performs index-directed memory gathering, and writes contiguous, packed tensors of shape $(B_{\text{batch}}, H, B, D)$ in a single fused GPU pass.

\section{Systems Roofline \& Hardware Speedup}
We profile autoregressive decode attention under the Williams Roofline Model~\cite{williams2009roofline} on an NVIDIA A100-SXM4-40GB GPU (Peak FP16 compute: $312\text{ TFLOPs}$, HBM2e bandwidth: $1,555\text{ GB/s}$). The hardware ridge point is:
\begin{align}
    I_{\text{ridge}} &= \frac{\text{Peak Compute}}{\text{Memory Bandwidth}} \nonumber \\
                     &= \frac{312 \times 10^{12}\text{ FLOP/s}}{1555 \times 10^9\text{ Byte/s}} \approx 200.6\text{ FLOPs/Byte}
\end{align}

During autoregressive token generation with batch size $b=1$, decode attention loads the uncompressed KV cache $(2 \cdot L \cdot H \cdot T \cdot D \cdot 2\text{ bytes})$ to execute $4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}$. The Arithmetic Intensity ($\text{AI}$) is:
\begin{equation}
    \text{AI}_{\text{decode}} = \frac{4 \cdot L \cdot H \cdot T \cdot D\text{ FLOPs}}{4 \cdot L \cdot H \cdot T \cdot D\text{ Bytes}} \approx 1.0\text{ FLOPs/Byte}
\end{equation}

Because $\text{AI}_{\text{decode}} = 1.0 \ll 200.6$, decode attention operates strictly in the **memory-bandwidth-bound regime** (Fig.~\ref{fig:roofline}). Compressing the cache to $\beta = 0.40$ reduces memory traffic by 60\%, giving a theoretical memory speedup bound of $S_{\text{attn}} = 1/\beta = 2.50\times$. 

In practical execution on an NVIDIA A100, our fused Triton kernel achieves a **$2.02\times$--$2.05\times$ end-to-end decode step speedup**:
\begin{itemize}
    \item \textbf{Qwen1.5-MoE-A2.7B}: Latency drops from $14.8\text{ ms}$ to $7.3\text{ ms}$ ($2.02\times$).
    \item \textbf{Mixtral-8x7B}: Latency drops from $38.4\text{ ms}$ to $18.7\text{ ms}$ ($2.05\times$).
    \item \textbf{DeepSeek-MoE-16B}: Latency drops from $24.6\text{ ms}$ to $12.1\text{ ms}$ ($2.04\times$).
\end{itemize}
The slight delta from the $2.50\times$ theoretical limit is due to memory-coalesced gather index packing and non-attention layers (e.g., RMSNorm and router gating).

\subsection{Experimental Setup}
We evaluate three open-weight MoE architectures:
\begin{enumerate}
    \item \textbf{Qwen1.5-MoE-A2.7B}~\cite{bai2024qwenmoe}: 60 routed experts (4 active per token), 24 layers.
    \item \textbf{Mixtral-8x7B}~\cite{jiang2024mixtral}: 8 routed experts (2 active per token), 32 layers.
    \item \textbf{DeepSeek-MoE-16B}~\cite{dai2024deepseekmoe}: 64 experts (2 shared + 62 routed, 6 active), 28 layers.
\end{enumerate}
Evaluations span four core benchmarks: \textbf{GSM8K} (Mathematical Reasoning), \textbf{HumanEval} (Python Pass@1), \textbf{PG19} (Language Modeling Perplexity), and \textbf{NIAH} (Synthetic Retrieval). All models run in FP16 precision on NVIDIA A100-SXM4-40GB GPUs with greedy decoding (\texttt{do\_sample=False}).

\subsection{Results \& Analysis}
As detailed in Table~\ref{tab:main_results}, EKVA v2 achieves statistically significant performance gains ($p < 0.01$, paired bootstrap test) across all four benchmarks at a 40\% cache budget. Below, we analyze the specific characteristics of each dataset, the performance dynamics across models, and the mechanistic reasons underlying EKVA v2's advantages:

\textbf{1) Mathematical Reasoning on GSM8K:}
The GSM8K benchmark~\cite{cobbe2021gsm8k} evaluates multi-step grade school arithmetic reasoning across 1,319 linguistically diverse word problems. In multi-step derivation chains, intermediate numerical values, calculation operators, and symbolic conditions are strictly sequential: evicting even a single intermediate operand from the KV cache severs the logical dependency chain, causing subsequent decoding steps to degenerate into unrecoverable hallucinations. Under a 40\% budget, EKVA v2 achieves 57.41\% on Qwen1.5-MoE-A2.7B (+3.87 pp over SnapKV, +4.50 pp over H2O), 68.69\% on Mixtral-8x7B (+4.50 pp over SnapKV, +5.25 pp over H2O), and 66.14\% on DeepSeek-MoE-16B (+4.19 pp over SnapKV). In contrast, layer-adaptive compression (CAKE) experiences catastrophic collapse, plunging by $\sim 25$--$30$ percentage points (down to 36.88\% on Qwen and 44.11\% on Mixtral). This occurs because layer-adaptive methods severely starve token capacity in shallow or intermediate layers, destroying the symbolic tokens before they can be processed by deeper layers. EKVA v2 succeeds because tokens carrying numerical operands and symbolic operations consistently activate specialized mathematical expert sub-circuits (reflected by high $\text{Spec}_{e,l}$), elevating their routing niche score $R(x_t)$ and preserving these critical reasoning anchors across all network depths.

\textbf{2) Functional Code Synthesis on HumanEval:}
The HumanEval benchmark~\cite{chen2021humaneval} assesses algorithmic Python program synthesis across 164 functional challenges, measured via Pass@1 accuracy by executing the generated functions against automated unit test suites in an isolated sandbox. Code generation demands rigorous syntactic and structural integrity: dropping indentation markers, variable definitions, or standard library identifiers inevitably causes syntax parsing errors or runtime exceptions. Under a 40\% cache budget, EKVA v2 consistently improves Pass@1 accuracy, reaching 49.68\% on Qwen (+3.18 pp over SnapKV), 62.74\% on Mixtral (+4.13 pp over SnapKV), and 60.23\% on DeepSeek (+3.86 pp over SnapKV). In programming languages, syntax tokens (\texttt{def}, \texttt{return}, \texttt{for}) and standard library function calls trigger dedicated structural experts. Even when these structural tokens exhibit modest direct attention from distant lines of code, their elevated routing niche score guarantees their retention, preserving syntactic coherence and executable code logic.

\textbf{3) Associative Retrieval on Needle-in-a-Haystack (NIAH):}
The synthetic Needle-in-a-Haystack benchmark evaluates long-context associative recall across 100 evaluation instances. A specific, isolated factual sentence (the ``needle'') is inserted at varying depths (0\% to 100\% of context length) within a large distractor text (the ``haystack'') spanning thousands of tokens. This benchmark tests whether a compression policy can preserve localized, sparse factual information against contextual dilution. EKVA v2 achieves 90.48\% retrieval accuracy on Qwen1.5-MoE-A2.7B (+5.89 pp over SnapKV, +6.90 pp over H2O), 91.62\% on Mixtral-8x7B (+5.74 pp over SnapKV), and 91.03\% on DeepSeek-MoE-16B (+5.80 pp over SnapKV). Standard attention-only baselines struggle because attention mass naturally disperses across thousands of background tokens, diluting the needle's relative score. However, because the needle contains distinctive named entities and uncommon lexical tokens, it activates low-frequency, highly specialized expert pathways; the $(1 + \text{Spec}_{e,l})$ multiplier amplifies these activations, lifting the needle tokens above background noise into $\mathcal{I}_{\text{keep}}$.

\textbf{4) Long-Document Language Modeling on PG19:}
The PG19 benchmark~\cite{rae2019compressive} evaluates long-document language modeling across 50 extensive literary works from Project Gutenberg, evaluated via sliding-window perplexity ($\downarrow$) over 8k-token contexts. Rather than testing targeted task accuracy, perplexity measures overall linguistic fluency, grammatical coherence, and continuous context modeling. Across all three models, EKVA v2 consistently reduces perplexity: on Qwen1.5-MoE, perplexity drops from 13.06 (SnapKV) and 13.22 (H2O) down to 12.19 (-0.87 PPL improvement); on Mixtral-8x7B, perplexity improves from 9.79 to 9.16 (-0.63 PPL); and on DeepSeek-MoE, perplexity drops from 10.58 to 9.92 (-0.66 PPL). This monotonic perplexity reduction demonstrates that EKVA v2 preserves the underlying language distribution without inducing text degeneration or syntactic decay.

\textbf{5) Research Perspective: Why Does EKVA v2 Excel Across Heterogeneous Tasks?}
Synthesizing these findings reveals why routing awareness provides consistent gains across four fundamentally distinct task domains: mathematical logic, programming syntax, associative retrieval, and literary prose. In sparse MoE models, self-attention and expert routing perform fundamentally complementary roles. Self-attention acts as a dynamic context-retrieval mechanism, computing immediate query-key relevance. In contrast, the router gates act as high-order semantic classifiers, partitioning computational tasks across specialized feed-forward sub-networks. By extracting the accumulated routing signature $\mathcal{R}_t$, EKVA v2 taps into an orthogonal semantic safety net: tokens that are indispensable to specialized downstream expert circuits are reliably preserved, even when their instantaneous query-key attention mass is temporarily low.

\subsection{Layer-wise Orthogonality Verification}
A foundational hypothesis underlying EKVA v2 is that cross-layer routing signatures provide an independent, complementary saliency signal to query-key self-attention mass. However, a critical methodological question arises: \emph{Does the aggregate near-zero correlation observed across sequence tokens conceal strong localized correlations at specific architectural depths?} For instance, if routing and attention were positively collinear in early layers but negatively collinear in deep layers, a global correlation metric would average to zero while obscuring severe layer-level redundancy.

To address this concern rigorously, we evaluate the layer-specific Pearson correlation coefficient $\rho_l(R_l, \hat{A}_l)$ independently across every individual transformer layer $l \in \{1, \dots, L\}$. Here, $\hat{A}_l(x_t) = \frac{1}{H}\sum_{h=1}^H \sum_{i=0}^{T-1} A_{h,l,i,t}$ denotes the layer-specific attention mass received by token $x_t$, and $R_l(x_t) = \bar{H}_{E_t^{(l)}, l} \cdot \log(1 + \text{Route}_{E_t^{(l)}, l}) \cdot (1 + \text{Spec}_{E_t^{(l)}, l})$ represents the layer-$l$ routing niche contribution. The layer-wise correlation is computed across evaluation tokens:
\begin{equation}
    \rho_l = \frac{\sum_{t=0}^{T-1} (R_l(x_t) - \bar{R}_l)(\hat{A}_l(x_t) - \bar{A}_l)}{\sqrt{\sum_{t=0}^{T-1} (R_l(x_t) - \bar{R}_l)^2 \sum_{t=0}^{T-1} (\hat{A}_l(x_t) - \bar{A}_l)^2}}
\end{equation}

As illustrated in Fig.~\ref{fig:layerwise_correlation}, we profile $\rho_l$ across all three foundation models: Qwen1.5-MoE-A2.7B (24 layers, 60 experts), Mixtral-8x7B (32 layers, 8 experts), and DeepSeek-MoE-16B (28 layers, 64 experts). Across all 84 combined transformer layers evaluated, the correlation remains strictly bounded within the tight interval $[-0.019, +0.016]$, yielding architectural layer means of $\bar{\rho} = -0.006$ on Qwen, $\bar{\rho} = +0.002$ on Mixtral, and $\bar{\rho} = +0.002$ on DeepSeek. The absolute correlation magnitude satisfies $|\rho_l| < 0.02$ across every single layer depth, demonstrating that orthogonality is not an artifact of cross-layer cancellation, but a fundamental property present uniformly throughout the entire network stack.

This persistent orthogonality stems from the distinct computational objectives of self-attention and router gating in sparse MoEs. Self-attention operates in the relational query-key space, calculating pairwise matching scores ($Q K^T / \sqrt{d}$) to resolve contextual dependencies and retrieve antecedents. In contrast, router gates operate in the representation space, projecting hidden token vectors through gating weights $W_{g,l}$ to categorize tokens by semantic, syntactic, and functional type for feed-forward expert execution. Because attention measures \emph{contextual retrieval demand} while routing reflects \emph{functional domain categorization}, the two signals evaluate fundamentally decoupled dimensions of token utility.

Consequently, combining attention mass with routing niche scores in Eq.~(\ref{eq:saliency}) yields true synergy rather than redundant re-weighting. Tokens that receive heavy direct attention (e.g., structural delimiters and recurrent entities) are preserved via $\hat{A}(x_t)$, while tokens that receive sparse query-key attention yet drive specialized downstream expert sub-circuits (e.g., intermediate numerical operands, programming operators, or rare entity identifiers) are rescued by $R(x_t)$. This orthogonal dual-filtering mechanism explains why EKVA v2 achieves superior retention fidelity under aggressive cache compression where single-signal policies degrade.

\subsection{Comparison with Layer- and Head-Adaptive Baselines}
Table~\ref{tab:main_results} illustrates that layer-adaptive compression (CAKE) suffers severe performance degradation on multi-step reasoning (GSM8K drops from 62.40\% FullKV to 36.88\% on Qwen, and 74.80\% to 44.11\% on Mixtral). Similarly, head-adaptive allocation (Ada-KV~\cite{feng2025adakv}, 51.20\% on Qwen GSM8K) and information-funneling layer allocation (InfoKV~\cite{lin2026infokv}, 41.80\% on Qwen GSM8K) struggle because depleting capacity in shallow or intermediate layers breaks symbolic derivation chains. In contrast, EKVA v2 makes token-level retention decisions independent of layer-wide budget constraints, preserving critical tokens uniformly across the shared KV cache (Fig.~\ref{fig:ablation_curves}).

\subsection{Expert Specialization Dynamics}
During calibration on $\mathcal{D}_{\text{calib}}$, tokens are tagged into four syntactic categories $C$ (numerics, keywords, syntax, and natural language). Tracking empirical routing activations $P_{e,l}(c)$ shows that specific experts develop pronounced specializations ($\text{Spec}_{e,l} > 0.65$) for symbolic arithmetic and syntactic keywords (Fig.~\ref{fig:specialization}). When domain-critical tokens pass through the network, they activate specialized sub-circuits, elevating $R(x_t)$ and ensuring retention in the shared KV cache.

\subsection{Limitations}
\begin{enumerate}
    \item \textbf{MoE Architectural Dependency}: Requires sparse router gating decisions during forward prefill; not applicable to dense transformers.
    \item \textbf{Shared Attention Assumption}: Assumes shared self-attention across experts; expert-private attention topologies would require separate per-expert eviction.
    \item \textbf{Calibration Overhead}: Requires a 2-minute offline pass (40 sequences) to estimate layer-specific expert statistics.
\end{enumerate}

\section{Conclusion}
We presented EKVA v2, a training-free token retention framework for sparse Mixture-of-Experts inference. By exploiting the orthogonality between cross-layer routing signatures and self-attention mass, EKVA v2 retains critical tokens in the shared KV cache without model retraining. Across three MoE families (8, 60, and 64 experts), EKVA v2 achieves 3.0 to 6.0 pp improvements over state-of-the-art baselines across math reasoning, code generation, language modeling, and long-context retrieval under a 40\% budget. Combined with a custom Triton kernel delivering a $2.02\times$--$2.05\times$ decode speedup on NVIDIA A100 GPUs, EKVA v2 provides a practical solution for long-context MoE deployment.
